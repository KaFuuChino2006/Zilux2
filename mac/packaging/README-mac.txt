Zilux2 for macOS (Apple Silicon) — 测试版说明
=================================================

这是 Zilux2 的 macOS 测试版（Apple Silicon / arm64），用于验证界面与在线音乐功能。
未做代码签名与公证（Notarization），首次打开需要手动绕过 Gatekeeper。

安装
----
1. 双击解压 Zilux2-1.0.0-arm64.zip，得到 Zilux2.app。
2. 把 Zilux2.app 拖到「应用程序」文件夹（推荐），或直接放在任意目录。
3. 打开「终端」，执行（把路径换成你的实际位置）：

     xattr -dr com.apple.quarantine /Applications/Zilux2.app

   如果不想用终端：在 Finder 里右键 Zilux2.app →「打开」→ 在弹窗里再点「打开」，
   之后系统会记住这个选择。

   macOS 15 (Sequoia) 及以上：如果右键「打开」没有出现「打开」按钮，
   去「系统设置 → 隐私与安全性」，在页面底部找到 Zilux2 的提示，
   点「仍要打开」（可能需要输入开机密码）。

首次启动
--------
- 应用会自己启动内置的本地服务（127.0.0.1 上的随机端口），无需额外安装任何运行时。
- 首次启动约 2~4 秒（Electron 冷启动 + 引擎就绪）。
- 界面与 Windows 版一致：首页、搜索、在线歌单、歌词页、「播放效果 → 房间」。

本测试版包含 / 不包含
---------------------
包含：
- 在线音乐（网易云 / QQ 音乐 / 酷狗 三个源，与 Windows 版同一套 API）
- 歌词（含逐词时间）
- 播放效果：关闭 / 纯字 / 房间（薄荷绿镜头隧道、逐词浮现、镜头推拉与晃动）
- 设置（含音量、音质、歌词字号等）

不包含（Windows 版有，本测试版故意移除或降级）：
- AirPlay 隔空播放（macOS 上不可用，入口已隐藏）
- 本地音乐库导入（暂未移植）
- 封面取色（回退到默认配色）、系统媒体控制中心集成（SMTC）
- 自动更新

已知问题
--------
- 未签名：首次打开必须按上面的方式绕过 Gatekeeper。
- 无本地库：设置里的本地音乐相关入口点了不会有反应。
- 无 AirPlay：找不到投送按钮是正常的。
- 如果 macOS 提示「无法验证开发者」，属于预期，用上面的方法打开即可。

反馈

后续主开发仍在 Windows 版。
