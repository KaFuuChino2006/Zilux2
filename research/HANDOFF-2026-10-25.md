## 7. 已知问题 / 限制

- SmartScreen 警告：安装包未签名 + 仓库私有，属预期。
- 应用内自动更新依赖 GitHub Release，private 仓库匿名 API 404；需仓库转 public 或配置令牌。
- 在线能力依赖本机代理（`127.0.0.1:7896`）：代理客户端未启动时在线搜索/下载/私人雷达会失败，本地曲库不受影响。
- 私人雷达依赖网易云登录 cookie；未登录时首页不显示雷达卡片、`kind=radar` 返回 401。
- QA 的 crossfade / tray 部分步骤会触发在线 QQ 搜索，网络抖动（502）会污染 console-error 断言，必要时单独重跑该套件。
- 标签写入仅支持系统有可写属性处理器的格式（MP3 / M4A / FLAC 可用；其余可能 `ok:false`），封面不写。
- 无损下载在音源不提供 FLAC 时自动降级 MP3（QA 按 SKIP 处理）。
- 迷你播放器动画期间（约 320/380ms）不响应再次切换；从最大化状态进出迷你态为即时落位（不补间）。
- 页面封面请求走 `http://127.0.0.1:<port>/api/cover`，控制台会有既有 Mixed Content 警告，图片实际可显示。
- 「歌词海报」已按用户要求移除（第二十三轮），设置导出/导入与其它功能不受影响。

## 9. 常用验证路径（手工）

- 迷你播放器：播放条右侧小方块按钮进 420×120 置顶小窗（320ms 补间 + 幕布 + 卡片入场），窗口四角为圆角、无灰边；Esc / 双击空白 / 再点按钮退出（380ms 反向动画）；迷你态 hover 播放键/歌名不动；迷你态刷新保持，App 重启回普通窗口。
- 私人雷达：首页「今日推荐」右侧卡片（未登录网易云时不显示）→「播放全部」/「查看全部」；雷达墙标题「私人雷达」、副标题「网易云 · 35 首 · 每天 6:00 更新」；「网格/横条」切换布局。
- 预告条：播放中看顶部胶囊倒计时（「N秒后切换」）；点「下一首」触发交叉淡化时变「正在无缝过渡到 X」，过渡完成变「正在播放」，全程不出现孤立「秒后切换」文字。
- 歌词海报：已移除——播放条不再有「享」按钮（只剩「词」）。
- 本地曲库：行内爱心=本地收藏、更多=收藏/编辑标签/添加到歌单/文件夹中显示/移到回收站；「我的歌单」侧滑「本地歌单」可建单/加歌/打开歌单墙。
- 无缝衔接：手动下一首听 1.2–2 秒过渡；`__ziluxCrossfade.snapshot()` 看 `crossfadeKind` / `nextPrepared` / `prefetchHit`；设置 → 播放有「播放速度」。
- 下载队列：进行中行可暂停/继续/取消；底部「清空已完成」只清记录。
- 设置：通用有「开机自启 / 监控本地文件夹」；播放有「睡眠定时 / 播放速度」；均衡器有「自定义预设」；数据页有「导出 / 导入设置、清理本地缓存」。
