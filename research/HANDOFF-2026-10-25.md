## 4. 构建 / 发布 / 部署（可复用命令）

```bash
# 前端（工作目录 web/）
"$NODE" ./node_modules/typescript/bin/tsc --noEmit
"$NODE" ./node_modules/vite/bin/vite.js build

# 只改前端时：直接把 web/dist 同步进安装目录
cp -rf web/dist/. "$LOCALAPPDATA/Programs/Zilux2/web/"

# 改了宿主（src/Zilux2）时：
E:/dotnet/dotnet.exe build src/Zilux2/Zilux2.csproj -c Release
taskkill //IM Zilux2.exe //F
powershell -NoProfile -ExecutionPolicy Bypass -File tools/publish.ps1 -SkipWebBuild -Configuration Release
cp -rf dist/Zilux2/. "$LOCALAPPDATA/Programs/Zilux2/"
# 启动（必须带 CDP 环境，用 pwsh）
$env:WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS='--remote-debugging-port=9223'; Start-Process "$env:LOCALAPPDATA\Programs\Zilux2\Zilux2.exe"
```

- 发布前校验 exe 没被写坏：`tr -d '\0' < dist/Zilux2/Zilux2.exe | wc -c` 应约 22,040,000。
- 前端改动的真机验证：重建 → `cp dist` → CDP `Page.reload {ignoreCache:true}` → 等 3~4s。
- CDP 脚本：repo 根目录**没有** `ws` 模块，用 Node 内置 `fetch` + 全局 `WebSocket`（Node 24）。

## 7. 已知限制（与 v1.1.9 相关）

- 倒计时只对「列表循环自然播到曲末」的长过渡显示；手动切歌 / 单曲循环 ≤2s 过渡不显示。
- 暂停、无下一首分析结果、未开启无缝衔接、迷你态均不显示。
- 本地曲目标签写入仍受系统属性处理器限制（DSF/APE/OGG/OPUS/WMA/AIFF 等可能失败，返回中文原因）；封面不写。
- 无损下载在平台未提供无损时会自动降级为高品质并记 QA SKIP。
- 仓库 private → 应用内自动更新不可用；安装包未签名，SmartScreen 属预期。

## 9. 常用验证路径（手工）

- 无缝过渡倒计时：列表循环播放某首、等无缝衔接 ready（约几秒），播放条下方出现「将在 X 分 Y 秒后过渡至 xxx」并逐秒递减；暂停 / 进入迷你播放器 / 过渡开始后提示消失。
- 迷你播放器：播放条右侧小方块按钮进 420×120 置顶小窗（320ms 补间 + 幕布 + 卡片入场），窗口四角为圆角、无灰边；Esc / 双击空白 / 再点按钮退出（380ms 反向动画）；迷你态 hover 播放键/歌名不动；迷你态刷新保持，App 重启回普通窗口。
- 私人雷达：首页「今日推荐」右侧卡片（未登录网易云时不显示）→「播放全部」/「查看全部」；雷达墙标题「私人雷达」、副标题「网易云 · 35 首 · 每天 6:00 更新」；「网格/横条」切换布局。
- 预告条：播放中看顶部胶囊倒计时（「N秒后切换」）；点「下一首」触发交叉淡化时变「正在无缝过渡到 X」，过渡完成变「正在播放」，全程不出现孤立「秒后切换」文字。
- 歌词海报：已移除——播放条不再有「享」按钮（只剩「词」）。
- 本地曲库：行内爱心=本地收藏、更多=收藏/编辑标签/添加到歌单/文件夹中显示/移到回收站；「我的歌单」侧滑「本地歌单」可建单/加歌/打开歌单墙。
- 无缝衔接：手动下一首听 1.2–2 秒过渡；`__ziluxCrossfade.snapshot()` 看 `crossfadeKind` / `nextPrepared` / `prefetchHit`；设置 → 播放有「播放速度」。
- 下载队列：进行中行可暂停/继续/取消；底部「清空已完成」只清记录。
- 设置：通用有「开机自启 / 监控本地文件夹」；播放有「睡眠定时 / 播放速度」；均衡器有「自定义预设」；数据页有「导出 / 导入设置、清理本地缓存」。
- 搜索框聚焦出现历史。
