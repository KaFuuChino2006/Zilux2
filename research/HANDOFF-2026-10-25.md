## 7. 已知问题 / 限制

- SmartScreen 警告：安装包未签名 + 仓库私有，属预期，可在安装说明里引导「仍要运行」。
- 应用内自动更新依赖 GitHub Release，private 仓库匿名 API 404；需仓库转 public 或配置令牌。
- 在线能力依赖本机代理（`127.0.0.1:7896`）：代理客户端未启动时在线搜索 / 下载 / 在线分析会失败，本地曲库不受影响。
- 标签写入仅支持系统有可写属性处理器的格式（MP3 / M4A / FLAC 可用；DSF / APE / OGG / OPUS / WMA / AIFF 可能返回 `ok:false`），封面不写。
- 无损下载在音源不提供 FLAC 时宿主自动降级为 MP3（下载队列会显示实际文件名），QA 已按 SKIP 处理。
- 睡眠定时「播完当前曲」依赖播放器 `ended` 事件；应用被强制结束后定时器随进程消失，不会残留。
- 音频分析缓存按 analyzer 版本分键：改分析算法必须 bump `AnalyzerVersion`（当前 p0-5）。
- 本地封面偶发 404（无内嵌封面的音频）属既有行为，回退渐变，不阻塞。

## 9. 常用验证路径（手工）

- 本地曲库：行内爱心=本地收藏（进「我喜欢的音乐」合并列表）、「更多」=收藏/编辑标签/添加到歌单/文件夹中显示/移到回收站；「我的歌单」侧滑「本地歌单」可建单/加歌/打开歌单墙。
- 无缝衔接：手动下一首听 1.2–2 秒过渡；看 `/tmp` 下 CDP 脚本或 `__ziluxCrossfade.snapshot()` 的 `crossfadeKind` / `nextPrepared` / `prefetchHit`；设置 → 播放有「播放速度」。
- 迷你播放器：播放条右侧小方块按钮进 420×120 置顶小窗，双击或 Esc 退出。
- 下载队列：进行中行可暂停 / 继续 / 取消；底部「清空已完成」只清记录。
- 设置：通用有「开机自启 / 监控本地文件夹」；播放有「睡眠定时 / 播放速度」；均衡器有「自定义预设」；数据页有「导出 / 导入设置、清理本地缓存」。
- 搜索框聚焦出现历史；播放条「享」打开歌词海报（1080×1440，可下载）。
