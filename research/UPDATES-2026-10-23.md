# Zilux2 更新文档（当前窗口汇总）

> 窗口时间：2026-10-22 ~ 2026-10-23
> 当前版本：**2.6.25**（安装包 `dist/Zilux2-Setup-2.6.25.exe`，安装目录 `%LOCALAPPDATA%\Programs\Zilux2`）

本窗口主要围绕「房间歌词效果打磨 → 在线能力补齐 → 本地曲库/下载完善 → 播放体验细节」四条线推进，共发布 2.6.9 ~ 2.6.25 共 17 个安装包。

## 二、在线能力（发现页 / 歌曲信息）

- 新增「发现」页（侧边栏「发现」）：排行榜（网易云 + QQ 30+ 榜单）、歌单广场、私人漫游、播客、收藏；支持二级页：榜单详情、歌单详情、歌手页、专辑页、评论 Sheet。
- 接入 10 个 `/api/discover/*` 接口；修复上游坑：网易云 `playlist/track/all` 下线（改 `/api/v2/playlist/detail`）、专辑曲目在 `album.songs`、QQ 歌单 GB18030 编码、QQ 榜单可用 `musicToplist.ToplistInfoServer/GetAll`、`imgcache`→`y.gtimg.cn` 封面、QQ 歌单广场封面/评论/歌手页/歌曲信息。
- **歌曲信息**：任意在线/本地曲目可查看（两种形态可设置）：整页详情（封面放大 + 歌手/歌曲信息折叠组）/ 列表内展开；显示来源、时长、发行日期、曲目、音质体积（QQ）、官方链接、歌曲 ID，可跳转歌手/专辑/评论。
- QQ 评论接入（`fcg_global_comment_h5.fcg`，需数字歌曲 id）；QQ 歌手页走 SSR `window.__INITIAL_DATA__`。

## 三、本地曲库

- **标签读取**：新增 `LocalTagReader`（MP3 ID3v1/v2、FLAC VorbisComment、M4A/MP4 ilst、OGG/Opus、WAV LIST INFO）→ 本地歌曲显示真实歌名/歌手/专辑，缺标签回退「歌手 - 歌名」文件名拆分。
- **歌手头像 + 艺术家页面**（2.6.13~2.6.15）：本地曲库新增「歌曲 / 歌手」切换；歌手网格显示头像（三级兜底：歌曲内嵌封面 → 在线网易云歌手图 → 首字母渐变）；点歌手进入详情（头像 + N 首歌曲 + 播放全部）；播放条歌手名与列表歌手文字可点击进入艺术家页。
- **管理功能**（2.6.10）：行内「在文件夹中显示」「删除（回收站）」，标题栏「打开文件夹」「刷新」；网格/横条两种布局都支持；删除后列表即时刷新。
- **下载/缓存可见**（2.6.9）：下载与实验源缓存统一进 `本地曲库`；缓存目录跟随下载目录；设置页显示缓存统计与「清空缓存」。

## 四、下载

- 统一下载：网易云 / QQ / 酷狗（如可播）/ 无名音乐 均可下载；横条模式每首歌右侧有下载按钮；下载完成即出现在「本地曲库」。
- 设置 → 下载：可改下载目录（默认 Windows 音乐目录）、「下载音质」三档（无损 / 高品质 / 标准，平台不支持自动降级）。
- 实测：QQ《晴天》无损 → `.flac` 55.4MB；网易云《宝船》标准 → `.mp3`；QQ 会员曲目可能提示「需要 QQ 音乐会员或已下架」（上游限制）。
- 无名音乐（实验源）：默认关闭，设置 → 实验功能开启并确认风险提示后，搜索等页面才显示；该来源播放时会后台缓存到本地（下载目录），供二次离线播放。

## 五、播放与界面体验

- **顶部「即将播放」预告条**（2.6.16~2.6.19）：任意页面顶部单框显示下一首（封面/歌名/歌手/专辑 + 倒计时），倒计时结束**同一框内连续过渡**为「正在播放」并停留约 2.6 秒后收起；倒计时数字渐变过渡（无弹跳）；点击整条可立即切歌；手动切歌同样显示「正在播放」。
- **首页改版**（2.6.7）：「网易云收藏」「QQ 音乐收藏」两张卡（封面叠放 + 播放全部 + 查看全部）占左侧/中间，「最近播放」收窄放最右侧。
- **顶部通栏**（2.6.6 前后）：鼠标移到窗口顶部时 44px 通栏出现（账号 + 窗口按钮），搜索框/品牌自动让位；离开后收起。
- **窗口动画设置**：设置 → 外观 → 窗口动画（应用内 / 系统原生）；应用内为最大化/最小化/关闭过渡（快照缩放淡出）。
- **应用内确认弹窗**（2.6.11）：删除/清空缓存等确认统一为应用内样式（模糊遮罩 + 卡片 + 危险红色按钮），不再使用系统原生 `window.confirm`。
- **统一的「效果设置」入口**：快捷设置「歌词」页只有一个「效果设置」按钮，按当前效果（纯字/房间）打开对应面板；切换效果时面板高度平滑动画；「动效」行只在关闭档显示。

## 九、已知限制

- QQ 搜索主接口偶发 500，会回退备用接口（首次搜索可能多等数秒）。
- QQ 会员曲目下载/播放受会员限制；部分 mvmp3 曲目上游已失效（403）。
- 本地头像依赖在线网易云歌手搜索，离线时回退首字母占位。
- 房间场景为 Canvas2D + DOM，性能依赖系统字体与显卡；低配机器可降「渲染像素比」。
