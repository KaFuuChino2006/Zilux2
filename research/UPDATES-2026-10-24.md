## 2. 本地音乐目录自动监控（新功能）

设置本地音乐文件夹后，宿主用 `FileSystemWatcher` 递归监听该目录；新增/修改/删除/重命名音频/歌词文件会自动刷新本地曲库（页面收到 `localLibrary` 事件自动重渲染），不用再手动点刷新。

- 新增 `src/Zilux2/Local/LocalFolderWatcher.cs`（约 560 行）：递归监听、InternalBufferSize 64KB、1300ms 静默去抖（单 Timer）、错误退避重启（2s 起、最长 30s）、`Start/Stop/Dispose` 幂等。
- 新增 `src/Zilux2/Local/LocalMusicService.Watch.cs`（partial，约 750 行）：
  - 生命周期：`Load()` 成功启动监听（先启动 watcher 再扫描）、切换文件夹时先停旧 watcher、失败/目录不存在时停掉并记日志、`Dispose()` 释放。
  - 事件处理：忽略 `~$`/`.tmp`/`.part`/`.crdownload` 等临时文件与隐藏文件；文件级变化走**增量单文件重扫**（只解析变化文件，UI 内存列表 diff 后只推变化项），批量/结构性变化（>30 项、重命名、目录变化）走一次整目录重扫。
  - 线程安全：事件在线程池线程，所有 `_post`/UI 交互经 `Dispatcher` 切回 UI 线程；`NotifyFileAdded`（下载完成）同样修正了跨线程问题。
  - 自写入抑制：宿主自己下载落地/删除文件时 15s 内不重复触发扫描（避免与 `NotifyFileAdded` 重复刷新）。
  - 日志：`[local] watch started: <dir>` / `watch stopped` / `watch event batch: N` / `watch incremental: +a -b` / `watch rescan` / `watch error`。
- 顺带修复（宿主）：`LocalMusicService.DeleteTracks` 删除文件后没有抑制自身写入 → 会被 watcher 再触发一次重扫；现在会先 `MarkHostWrite`。
- 已知限制：网络盘/超大目录只保证不崩，实时性取决于系统事件；监控不提供设置开关（默认开启）。

## 8. 同日第三轮：纯字档背景光柱重做（已推 main，未发版）

用户反馈「文字效果 → 纯字」里的背景光束位置/变化不对（迁移后遗症），要求删掉现有光柱、自己做一组等量的新光柱。本轮按 HANDOFF §9 判定：累计 **5 处修复/优化、无新增功能**（3 项下载队列 UI 微调 + 搜索竞态修复 + 本次光柱重做），未超 5 处 → **只推 main，版本仍 1.1.4、不打 tag、不发 Release**。

- **问题根因**：纯字档此前复用 `lumiere-folia` 光位目录里的镜头光束（`light/rigs/*.ts` + `catalog.ts`）。那些光束的发射点/角度/长度是按「3D 房间镜头」的投影设计的；纯字档把画面当 2D 背景铺满窗口后，位置和运动与文字版面/构图对不上，且不同镜头套数（最多 6 道）的分布很随意。
- **新方案（自研）**：纯字档的 `beamsOnly` 分支不再计算/使用 folia 镜头光位光束，改为 `resolveTextBeams()` 生成的固定构图：
  - 数量恒为 `TEXT_BEAM_COUNT = MAX_BEAMS`（6 道，与迁移版每套光位上限定一致＝等量）；
  - 画布比例坐标 `x: 0.05/0.24/0.50/0.62/0.76/0.94`，垂直光柱（`angle: π/2` ± 少量散光），中心束对准文字区、两侧作环境光；
  - 运动：每束独立极慢摆动（11–23s 周期、±0.02 振幅）+ 长度呼吸 + 低频驱动抬升亮度，不再出现镜头运动会带来的乱走；
  - 设置面板的「背景光柱 / 光柱大小 / 左右位置 / 上下位置」继续生效（scale/offset 作为求解参数传给 resolver）；光场、文字照明、残影回声使用同一组解算结果，保持一致。
- **实现**：新增 `web/src/ui/lumiere-folia/components/visualizer/lumiere/light/textBeams.ts`（约 145 行，Zilux2 自研，中文注释）；`scene.ts` 的 `beamsOnly` 判断提前、该分支改用 `resolveTextBeams`（`import { resolveTextBeams }`），非纯字档的 folia 光位链路保持不变。
- **验证**：真机打开纯字档播放截图（`research/shots/beams-live-1.png` ~ `beams-live-3.png`、`beams-final-1/2.png`）；文字设置面板切「背景光柱」关→预览明显变暗、开→恢复；光柱大小/左右/上下滑杆联动正常；`tsc --noEmit` 0 error、`vite build` 918 modules 通过、publish 并同步安装目录、重启后无 console error。

## 9. 同日第四轮：纯字光柱多套效果 + 烟雾/光柱无缝循环（已推 main，未发版）

用户反馈「光柱效果只有这一种吗，而且还是不循环的，能看到头尾的变化」以及「烟雾不是循环的」。本轮在 §8 自研光柱的基础上补两件事：**光柱风格可选**、**光柱与烟雾全部无缝循环**。

- **四套光柱风格**（文字设置 → 光柱效果）：`静光`（calm，默认，6 道固定构图垂直光柱）、`缓息`（breathe，4 道向中心收拢、呼吸式起伏）、`流幕`（curtain，5 道宽幅光幕、层叠流动）、`聚光`（focus，4 道强光束向文字中心汇聚）。每套都有独立的发射点构图、宽度、亮度与动法；切换即时生效（设置面板预览、歌词页同步），无需重开页面。
- **无缝循环（核心）**：
  - 新增 `textClock()` 全局时钟，循环周期 `LOOP = 32s`；每道光柱的摆动/呼吸/漂流相位都取 `LOOP / 整数谐波`（如 32s、16s、8s、4s…），因此 32s 后画面与开头完全重合，**看不出头尾**；也避免换歌/拖进度时因时间跳变产生跳帧。
  - 光柱的 `streakPhase` 不再用原始 `time` 线性推进，改为按循环圈数取整（`cycle = (time % LOOP)/LOOP`），避免光带纹理在循环点跳变。
  - **烟雾无缝循环**：纯字档的雾改为固定 `TEXT_FOG_RIG`（不再随镜头光位换雾参数），并给光场 shader 增加循环雾模式：新增 uniform `uFogC`（模式、相位、振幅）与 `fogLoop` 配置（周期 42s、漂移振幅 x/y）。循环模式下雾的漂移取 `sin/cos` 而不是原来的线性 `uFogB*t`，流动纹理相位按整圈取余 → 原路返回、首尾衔接，不会出现「雾突然跳一下」。
- **实现文件**：`light/textBeams.ts`（重写：`TEXT_BEAM_STYLES`、四套 `COMPOSITION`、`TEXT_FOG_RIG`、`TEXT_FOG_LOOP`、`textClock()`、`resolveTextBeams({style})`）；`light/lightFieldShader.ts`（`uFogC` uniform + 循环雾分支 + `fogLoop` 配置贯通）；`scene.ts`（纯字分支传 `textClock()`/`style`/`TEXT_FOG_RIG`，`field.update` 增 `fogLoop`）；`lumiereSettings.ts`（新增 `beamStyle` 字段 + 默认 `calm` + 归一化 + 转 tuning）；`textSettingsPanel.ts`（新增「光柱效果」分段行，4 个按钮，hint 说明四套均走 32 秒无缝循环）；`lumiere-folia/types.ts`（`textBeamStyle` 字段/默认值）与 `lumiereRuntimeTuning.ts`（`textBeamStyle: tuning.textBeamStyle ?? 'calm'`，运行中切换即生效）。
- **验证**：真机打开文字设置，「光柱效果」四个按钮依次点击，预览截帧 `research/shots/beamstyle-preview-{calm,breathe,curtain,focus}.png` 风格差异明显；打开歌词页纯字档截帧 `research/shots/beams-ear2-1.png` ~ `beams-ear2-3.png`（间隔数秒，光柱缓慢轻摆、雾持续流动）；`tsc --noEmit` 0 error、`vite build` 918 modules 通过、publish 并同步安装目录、重启后无 console error。
- **发版判断**：三轮累计已超过 §9「累计修复/优化超过 5 处」的门槛，但按用户当前要求（先自测，不要反复验证）**先只推 main**，不 bump 版本、不打 tag；待用户确认效果后再决定是否发 1.1.5。

## 10. 同日第五轮：光柱多入射角 / 彩虹色 / 自动轮换（已推 main，未发版）

用户反馈「光不止有这一种入射角，还有多角度的、多样化的、彩虹色的，自动轮换的」。本轮把纯字档背景光柱从 4 套扩到 **8 套**，并加入自动轮换。

- **四套新样式**（文字设置 → 文字 → 光柱效果，8 个按钮分两行）：
  - `斜光`（diagonal）：6 道同向 30° 斜射、右下角落点，右侧一道反向压边、上方一道斜顶光；
  - `交叉`（cross）：左右两对反向斜射在文字区交叉成 X 形，中间加一道竖直补光；
  - `仰光`（rise）：6 道自下而上从画面底部升起的光柱，低位叠一层散光；
  - `虹光`（rainbow）：6 道从文字区中心向外扇形散开的光柱，每束不同色相（品红/金/青绿/蓝等），并叠加 shader 的截面色散。
- **自动轮换**：新设置 `beamAuto`（默认开）。开启后每 16s 换一套样式，顺序 静光→缓息→流幕→聚光→斜光→交叉→仰光→虹光 循环；切换用 2.4s smoothstep 过渡，两套光柱的位置/角度/宽度/亮度/方向做插值（方向向量归一化，不会变短），看不出硬切。所有样式统一走 §9 的 32 秒循环时钟。
