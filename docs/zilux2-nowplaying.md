# Zilux2 沉浸播放页（Now Playing）v1 — 接口与验收草案

> 状态：草案（Lead 维护，2026-10-18）。等待用户确认需求后转为正式任务契约。
> 目标：点击播放条进入整页沉浸播放视图，3D 歌词舞台为主视觉，白磨砂体系，与现有播放器/歌词/音频特征总线复用。

## 1. 入口与路由

- 入口：
  - 点击播放条左侧「封面 + 曲名」区域（`data-open-nowplaying`）；
  - 键盘 `Ctrl+P`；
  - 3D 歌曲页顶部「正在播放」胶囊（后续）。
- 关闭：`Esc`、左上返回按钮、再次点击播放条标题。
- QA 参数：`?mock=1&panel=nowplaying`（无宿主演示数据）；`?snap=1` 冻结动效。

## 2. 布局（1600×960 基准）

```
┌───────────────────────────────────────────────────────────┐
│ 返回  正在播放 · 网易云                         [更多] [×] │  ← 顶栏 64px
├──────────────────────────────────┬────────────────────────┤
│                                  │  ┌──────────────┐      │
│      3D 歌词舞台（canvas）        │  │  3D 封面卡    │      │
│      当前行扫光 + 上下各 2 行      │  └──────────────┘      │
│      微弧面 / 白磨砂倒影           │  曲名 / 歌手 / 专辑     │
│                                  │  [收藏] [加入歌单] [评论]│
├──────────────────────────────────┴────────────────────────┤
│  [shuffle] [prev] [play] [next] [repeat]   进度 · 音量 · 歌词 │  ← 复用播放条
└───────────────────────────────────────────────────────────┘
```

- 页面层：`position: fixed; top: 38px; left: 84px; right: 0; bottom: 0; z-index: 32;`（在播放条之上、标题栏之下；播放条保留，避免重复造控制条）。
- 背景：白磨砂（`--glass` 叠层 + 浅色极光），歌词舞台是唯一 WebGL canvas；封面卡为 CSS 3D transform（无第二 WebGL 上下文）。
- 响应式：宽度 < 1100px 时歌词舞台占满、封面卡缩为顶部小卡；超宽屏内容 `max-width: 1720px` 居中。

## 3. 数据与引擎

- 数据来源：`player.current()` 返回 `NowPlaying`（online 分支含 `OnlineTrack` + queue）；歌词走 `fetchLyric` + `parseLrc` + `applyTranslation`（复用现有管线，不新建 API）。
- 3D 引擎：`web/src/three/lyricsStage.ts` 的 `createLyricsStage(canvas, opts)`：
  - `setLines(StageLine[])`（秒级 startTime/endTime，行级）；
  - `setTime(currentTimeSeconds)` 由 `player.onTime` 驱动；
  - `resize()` 用 ResizeObserver 去抖（200ms），`start()/stop()` 跟随页面可见性，`dispose()` 在关闭页时释放；
  - 歌词面板右侧的 2D 版本与 3D 舞台二选一显示（页面切换按钮「3D / 列表」）。
- 音频特征：`audio.latestAudio()` 每帧读取，`level` 映射到舞台轻微景深/边缘光（≤3% 幅度），`beat` 触发 120ms 微脉冲；`reduce-motion` 或 `audioReactive=false` 时增益归零。
- 若歌词为行级 LRC（无逐字）：按行扫光（`uProgress` = 行内时间比例）；逐字数据后续里程碑再做（engine 预留但 v1 不接）。

## 4. 状态

- 加载：歌词 fetch 中显示骨架（舞台底部 3 行灰条）；
- 无歌词：显示「纯音乐 · 暂无歌词」（不画占位歌词）；
- 错误：显示「歌词加载失败 · 重试」按钮，保留封面/控制可用；
- 切歌：舞台 `setLines` 新歌词 + 300ms 淡入；封面卡换图淡入；不重建 WebGL 上下文。

## 5. 验收（用户自测）

- 从播放条进入/`Esc` 退出流畅，无黑屏、无闪烁；
- 歌词随播放高亮、点击行 seek、切歌同步；
- `reduce-motion` 下无扫光/呼吸/过渡；
- 1600×960 与 3440×1440 两档布局不溢出；
- `pnpm build` 通过（tsc strict）。

## 6. 非目标（v1）

- 不做逐字卡拉 OK（需要 word 级时间轴与更多 shader 工作）；
- 不做歌词样式自定义（字号/字体/布局在设置已有基础项）；
- 不做 MV/PV 视频背景（另立里程碑，需 LibVLC 原生层）。

## 7. 后续里程碑（占位）

- v2：逐字歌词 + 段落特效（Folia 式 chorus 处理）；
- v2：PV 播放画面（宿主 LibVLC 层 + 页面 3D 叠加，二选一解码路径）；
- v3：桌面歌词/壁纸模式复用同一舞台引擎（WorkerW 层）。
