# Zilux2 v1.1.9 — 更新内容

本版本为 v1.1.8 之后全部改动的累积更新。

## 新增功能

- **歌词播放样式**：经典 / 上浮 / 波浪 / 摇曳 / 打字机 / 旋入，六种只改「播放动画」的样式；颜色仍由「歌词颜色」控制。旋入为文字随机飘入组成句子，未播放行按距离打乱、越靠近播放行越整齐，唱过的字会缩小落回。
- **歌词衔接**：上一首末句唱完立刻接下一首首句，人声先出、伴奏渐入；人声约 2–6 秒缓慢浮现，并用 1.8 kHz 人声聚焦 EQ 分离伴奏；过渡时长按两首协调后的真实小节计算，尾奏较多时先保留一段尾奏再交接；自动过滤作词 / 作曲等制作人员名单，不再把名单行当成人声起点。
- **系统媒体键接管**：即使键盘媒体键已被 QQ 音乐等程序抢注，Zilux2 是当前播放器时仍由 Zilux2 响应播放 / 暂停 / 上一首 / 下一首；其它程序在放歌时媒体键仍交给它们。
- **平台登录状态检测**：后台定时校验网易云 / QQ 音乐登录态（启动约 20 秒首检，之后每 5 分钟），掉登录时前台 toast、托盘气泡与账号面板「登录已失效」提示，设置 → 账号可手动检查。
- **便捷设置**：新增歌词样式行；「封面」页背景支持 关闭 / 随歌曲封面 / 自定义图片 三档（与设置 → 外观共用状态）。
- **单实例运行**：重复启动只唤出已有窗口，不再出现多窗口 / 多托盘 / 多套热键；隐藏到托盘时二次启动会自动唤起。
- **禁用双指缩放**：应用内关闭 WebView2 的捏合缩放与缩放入口，界面不会被误放大。
- **全局交互动画补全**：按钮按压反馈、页面 / 列表进场、浮层退场、下载队列落地反馈、点赞动画、设置页切换淡入、键盘焦点环等。

## 修复

- 迷你播放器 v2：排版与画面裁切、窗口圆角、悬停位移、顶部预告条倒计时闪现。
- 歌词页：浅色主题可读性、遮罩发虚与尾部变淡、被首页整层压住（入场动画 fill-mode 覆盖隐藏）、浅色主题换深字。
- 歌词样式：渐变样式叠字重影、打字机换行瞬间整句闪一下、弹跳幅度过大改为摇曳、漂浮改为旋入、上浮 / 旋入样式下方未播放行可见度不统一、旋入换行重新组装。
- 播放条常驻展开时悬停内容位移、本地歌单新建后行渲染异常、首页「私人雷达」卡片、无缝过渡倒计时提示位置与时长标注。
- 更新页：已是最新版本时仍显示灰按钮（`.btn` 自带 display 盖掉 `[hidden]`）。
- 便捷设置：背景分段高亮错位。
