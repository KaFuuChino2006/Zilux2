# Zilux2 v1.2.14

这一版把重合模式的「曲名卡」补上，并重做混音过渡里人声让位的收尾与起压；顺带把闪烁退场收紧到 0.3 秒内四次。

## 新增

- **重合 · 曲名卡**：第一句唱词开口前淡入一次（提前 0.85 秒开始退，正好在第一句出来时收干净），全曲唱完后再淡出一次。卡面只显示歌名，版式用重合自己的语言——纸底、标题上下一两笔手写弧、方括号括住歌名，不套拼合档的圆盘拼贴。开关在「重合设置 → 文字 → 曲名卡」，默认开启。
- **歌词头部署名整行剔除**：歌词文件开头的「词：」「曲：」「编曲：」「OP/SP」这类署名行不再进排队、也不会被当成一句歌词画出来（只作用于重合档）。

## 修复

- **重合 · 开场曲名卡看不见**：卡片其实已经建好，但入场动画取的是「相对片尾」的时间，开场时是个几百秒的负数，每一条都被判成还没入场、alpha 全是 0。现在开场时段改用歌内时间（0 起算），正常淡入。
- **混音 · 过渡完成瞬间压着人声的东西突然消失**：让位曲线在过渡末尾的最后 25%（至少 0.6 秒、最多 4 秒）不再起新的让位，release 自己把深度送回 0 dB；曲线已经放平就不补 ramp。
- **混音 · 起压太硬**：触发放回「B 唱就压 A」的听感，但起压从 30 ms 改成 420 ms 缓坡；A 处在器乐/换气时只轻收（×0.3），深度仍封顶 3.5 dB。
- **闪烁退场**：重做成固定 0.3 秒内四次（每闪约 75 ms，亮 55% / 暗 45%），闪完立即不可见，剩余退场时间保持黑；相位取整句，整行一起闪。

## 说明

- 曲名卡的配色/字体跟随当前风格预设，换歌会跟着封面主色走。
- 混音这两处都补了回归用例：起压必须是缓坡、收尾前必须自己放平不留缺口。
