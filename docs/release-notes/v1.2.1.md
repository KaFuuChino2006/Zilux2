# Zilux2 v1.2.1

这一版把进阶混音 v2 从「能接」推进到「按曲风接」：先给每一首算一份风格画像，再按画像调换手窗口、频段占比与人声交接点；低频反相、分频点、B 侧电平补偿这些会让过渡「越换越薄」的坑，现在在规划期就算清楚；A 的尾奏不够长时，改用循环单元自延长补齐。分析链路改成两段式——基础分析照旧立即返回，分轨活动度、结构、风格特征由宿主在后台补齐，界面按需取用。界面侧修掉两处手感问题：首页入场落定瞬间的像素位移、壁纸页左右不对称，并把托盘右键菜单换成与应用同一套材质的自绘面板。

## 新功能

- **风格画像与风格化过渡**：从活动度曲线、谱特征、元数据与歌词算出多标签风格得分、主风格、mood、人声三态与语言，再据此调整进阶混音 v2 的换手窗口、频段占比与人声交接点，并给两侧分别加一条风格 EQ——A 侧补空气感与咬字亮度，B 侧补低频架；全部为 0 dB 时链路与旧版逐位一致。画像在谱特征到齐前显示「待补谱特征」，不阻塞播放。
- **A 尾自延长**：过渡需要更长尾段而 A 的尾奏不够用时，按可循环单元平铺补齐；B 的前奏不够则复用前奏重复段。接缝要同时过三道质量门（能量跳变、谱质心漂移、响度差），最长 32 秒 / 8 小节，接缝按采样级对齐。
- **增强分析两段式**：宿主在基础分析成功后把分轨活动度、SSM 结构、风格特征排入后台队列；新增 `GET /api/analysis/features`，可在返回基础结果时内联已就绪的部分，其余进 pending 由前端补齐。特征键不含分析器版本，模型升级只失效对应的那一段。
- **首页「推荐式」排版**：今日推荐与最近播放新增唱片档案式排版，选择按页面记忆，切换走与换页同一套出入场。
- **托盘菜单重做**：系统右键菜单换成与应用同一材质的卡片面板——品牌标头、分区细线、浅金悬停、退出项用告警红，带键盘上下选择、Esc 收起、失焦自动收起、贴边翻转，不进 Alt+Tab。

## 改进与修复

- **低频反相**：两侧低频相关为负时先翻 180° 再相加，避免线性换手把低频抵消成一条薄带；分频点按低频相关性在 120–180 Hz 之间规划。
- **B 侧电平补偿**：以 A 的峰值为参考生成一条只压 B、不动 A 的补偿曲线；渐隐起点补 250 ms 斜坡，消除台阶感。
- **人声交接**：人声尾音守卫会避开上一首的拖音，入点清晰度用来判断 B 是否真的开唱，模糊时退回句边界。
- **配对降级**：计划超过 5 秒一律走 v2；只有速率不可信、超出安全拉伸、几乎没有拍点的配对才退回标准路径。
- **变速上限**：按变调可闻度设成 A 侧 ±3%、B 侧 ±4.5%，超限不再拉音高，改用拍点相位对齐。
- **歌词页减负**：画布舞台按需创建，逐字节点只建当前行附近，行级可见性由 `IntersectionObserver` 管；进度文本与进度变量只在值变化时写。
- **封面歌词逐词扫光**：按词时间推进，相邻词边界速度取调和平均，交接不会忽快忽慢。
- **首页入场落定**：落定后保留合成层，不再在结束瞬间统一回主线程栅格化——那一次切换会让 92 个块同时从分数位置吸附到设备像素、文字从灰阶抗锯齿换成次像素抗锯齿，表现为整页「咔」一下。
- **壁纸页左右对称**：左右内边距统一，并给滚动条留双倍槽位，有无滚动条都不偏。
- **歌词页不显示导航条**：歌词页铺满整窗，上方悬浮导航条整体停用——不仅默认收起，把指针移到它原来的位置也不会出来；关掉歌词页后按所在页面恢复（首页常驻、其它页面悬停显隐）。
- **混音浮层改为只读诊断面板**：去掉会改声音的分轨试听与增益控件，改为显示两侧风格与当前过渡的读数。

## 已知限制

- 进阶混音 v2 仍只在两侧都接进音频图（图模式）的过渡里生效。
- 延长段最长 32 秒 / 8 小节，超出按可缓存长度截断。
- 风格画像依赖谱特征；纯人声、极短片段或分析失败的曲目可能只给出语言与人声判断，不给主风格结论。
