# Zilux2 v1.1.93 — 更新内容

本版本为 v1.1.92 之后的体验修复与设置补充。

## 新增功能

- **「打开软件直接播放」**：设置 → 播放 → 打开软件直接播放。可选来源：
  - 今日推荐（合并所有已登录平台的每日推荐）；
  - 我喜欢的音乐（合并所有已登录平台的收藏）；
  - 指定歌单（在应用内选择任一平台的歌单）。
  打开软件后自动开始播放；未登录或来源为空时静默跳过，不影响正常进入应用。

## 修复

- 修复平台账号头像与昵称偶发消失：登录状态定时校验只更新登录态，不再覆盖已缓存的头像 / 昵称 / 会员资料。
- 修复搜索框层级异常：进入歌词整页或打开设置等全屏层时自动收起搜索，搜索展开态的层级管理改为显式状态类，避免个别环境下搜索框浮在其它画面上方的问题。
