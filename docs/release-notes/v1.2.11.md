# Zilux2 v1.2.11

这一版把「装完就能用」的体积问题收回来：人声分离模型不再随安装包分发，首次用到时自动下载并校验；左下角新增长驻进度卡，模型下载、人声分离、切歌手法都在同一张卡里显示。界面侧补了两处日常手感——关闭按钮可选「缩到后台 / 直接退出」，顶端通栏改为离开后 200 ms 再收起。窗口动画回到 Windows 原生补间，不再有忽快忽慢的自绘动画。混音修正了一处判断错误：自动过渡不再按 B 的唱句反复压低正在播放的那一首。

## 新功能

- **人声分离模型按需下载**：模型不再打进安装包，安装体积从约 225 MB 降到约 93 MB。首次切换到人声/伴奏时自动下载约 130 MB 模型，下载完成后校验 SHA-256，通过才落盘启用；下载失败会保留原声并提示重试。
- **左下角常驻进度卡**：模型下载、人声分离、切歌手法共用同一张卡片，显示阶段、网速、进度与已处理量；可收起成左边缘的窄条（带进度环），点箭头随时展开，任务完成后自动淡出。
- **切歌手法显示更完整**：过渡时的手法卡覆盖 16 种混音手法（长混音、低频换手、三段 EQ、双扫、回声收尾、混响收尾、连滚 loop、回旋刹车、砸切、交换 drop、双 drop、叠播加厚、清唱叠加、半速切换、升调推进、硬切），并补充桥接小节数、变速幅度、低频交接、人声对齐、节拍咬合、调性与 BPM 差等细节。
- **关闭按钮行为可选**：设置 → 通用 → 关闭按钮，可选「缩小到后台」（继续播放并驻留托盘）或「直接退出」（结束进程）。托盘菜单的「退出」始终是直接退出。

## 改进

- **窗口动画回到系统原生**：最大化、还原、最小化、关闭重新使用 Windows 的补间动画；窗口仍是铺满的无边框样式，标题栏语义只在系统层生效。
- **顶部通栏延迟收起**：指针离开后保留 200 ms 再收起，滑进滑出不再一触即走。
- **修正自动过渡把正在播放的歌压闷**：人声让位改为只在两首歌的人声真正撞在一起时生效，深度封顶 3.5 dB，任一方停唱立即放开；此前基于错误判断调整的滤波与增益曲线退回原调校值，A 的厚度与亮度保持不变。
- **过渡窗口口径统一**：同平台与跨平台之间的时长差异只来自是否命中风格选型，不再被尾段补时逻辑额外撑长。

## 修复

- **人声分离点了没反应**：ONNX Runtime 依赖从 DirectML 1.24.4 换回 CPU 版 1.31.1，修掉加载模型时的 DFT 属性冲突。

## 已知限制

- 首次人声分离需要联网下载模型（约 130 MB）；离线环境可用 `tools/publish.ps1 -WithModel` 打全量包，或手动把模型放进 `%LOCALAPPDATA%\Zilux2\models\`；设置 `ZILUX2_STEMS_NO_DOWNLOAD=1` 可关闭自动下载。
- Release 页面单独提供 `htdemucs-dft-fp16-transparent.onnx`，供离线安装使用。
