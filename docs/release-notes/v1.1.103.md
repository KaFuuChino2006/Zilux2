# Zilux2 v1.1.103

这一版把「桌面背景歌词」的画面链路收干净了：封面在左时可以真正做到封面往壁纸里渐隐、模糊可以按档位平滑变化、切样式不再漏出封面的模糊层；顺带补上了「下一首取不到流（下架 / 版权）」时的自动跳过，以及纯壁纸下歌词起句从中间弹出。

## 新功能

- **取不到流自动跳过**：下一首的音频流 404 / 被拒时，不再停在过渡画面，自动跳到后面能播的一首，并弹一条「「歌名」暂时无法播放，已自动跳过」。连续失败会在 3 次后收手，避免在整张下架专辑里空转。

## 改进与修复

- **渐隐到壁纸时右侧仍是封面**：铺满用的那层封面模糊带着一段入场动画留下的内联 `opacity:1`，类规则压不过它，右缘一直被封面自身盖住；改为只由类控制显隐，内联值一并清掉。
- **封面模糊的进场**：不再用 `backdrop-filter` 做动画（桌面歌词窗口里它不逐帧重绘），改成常规 `filter: blur()` + 常驻 `transition`，摸不到「先糊后清晰」的跳变。
- **模糊开关的进出**：过渡声明挪到常驻的场景规则上，从「有模糊」切到「不模糊」也有 520ms 渐变（此前只有反方向有）。
- **模糊档位不变**：`--bg-cover-blur` 原来只写在 `.lyrics-view` 上，而默认效果下壁纸层挂在 `document.body` 上继承不到，永远落 44px 兜底；现在同时写到 `<html>`，轻/中/重分别是 20 / 44 / 64px。
- **铺满模式的档位过渡**：铺满走封面自己的模糊层，这条规则缺 `transition`；后加的那条又用 `transition: opacity` 把 `filter` 整条覆盖掉，补齐为 `filter .52s, opacity .52s`。
- **铺满时背景不糊 / 切回渐隐后封面不糊**：`fill`/`edge` 的差异改为两条模糊带做 `opacity` 交叉淡入（合成属性，必有中间帧）；壁纸层的模糊两种模式都挂。
- **切样式时画面位移**：`scale(1.06)` 原来是「封面在左」专属，切到纯壁纸时被撤掉会跳一下；改为场景级常驻。
- **纯壁纸下的起句动画**：居中排版的歌词不再沿用主歌词页「行首弹起」的原点，改为从中心放大；「封面在左」保持原来的行首弹出。

## 已知限制

- 桌面歌词窗口的 WebView2 在部分机器上只在重新显示时整体重绘，页内动画的观感以最终态为准；静态度量（模糊半径、遮罩、透明度）都已验证到位。
- 主屏以外屏幕的桌面歌词暂不叠加（只覆盖主屏）。
