# Zilux2 v1.1.97

这次更新以全链路修复为主：把设置、播放、桥接、下载、更新与 AirPlay 的已知问题集中清理了一遍，并补上了歌词页的第五种播放效果「几何」。同时不再让本地音乐的转码/分析缓存长期占用 C 盘空间。

## 新功能

- **歌词「几何」效果**：歌词页新增文字 PV 风格的几何场景，每句自动换构图（横条压字 / 竖排 / 巨字裁切 / 镜像 / 网格 / 跑马灯 / 画框 / 拼章），配青品两路错版、半调网点与裁切标记；快捷设置 →「几何设置」可调配色预设、字形字距、构图模板、逐字点亮与颗粒。
- **恢复全部默认设置**：设置页底部新增入口，二次确认后把全部设置还原为出厂默认。
- **音频反应开关**：设置 →「音效」新增「音频反应」，关闭后不再采集播放音频，效果停在静态值。

## 改进与修复

- **设置**：修复在线音质、直连 GitHub、实验音源默认平台等选项保存后不生效或重启回退；导入设置时保留未覆盖的段并立即刷新面板；桌面歌词与桌面背景歌词改为互斥；依赖开关（渐变、桌面歌词子项、背景歌词样式、更新方式、开机自启子项）在总开关关闭时正确禁用；快捷键总开关关闭后不再录入；Esc 可关闭设置面板；滑块发送做节流；不再出现导入双提示。
- **快捷键与托盘**：12 个全局快捷键全部接通；托盘新增「设置…」；媒体键与媒体会话重复订阅、禁用后不释放的问题修复；单实例激活不再把最大化窗口还原。
- **桌面歌词 / 背景歌词**：背景歌词窗可收到在线播放信息；消息入口增加来源与大小校验，初始化失败会回滚开关而不是留下空白窗；歌词窗的字体、颜色、锁定、置顶与位置会持久化；迷你模式相关设置运行中修改即时生效。
- **播放与歌词**：睡眠定时「播完当前曲」按真实曲末触发，不再提前 300ms 或先恢复音量再暂停；无歌词时不再每帧重复拉取与重绘；背景歌词跟随字号、字重、纯色颜色与封面模糊；歌词偏移在拖动进度后仍准确；换歌封面交叉淡入不再残留旧图；节拍器跟随播放速率；交叉淡化残留的 seek/预设问题修复。
- **本地音乐与下载**：ALAC/DSF 转码缓存与在线节拍分析音频改为临时文件，启动/退出清理，分析完成即删除，不再长期占用 C 盘；下载校验 Content-Length、短读不再覆盖成品；同名文件自动避让；支持断点续传与多下载根；目录监控合并曲目时保留时长/起始时间/Cue；MVMP3 播放地址缓存改为并发安全。
- **更新**：更新包强制校验 SHA256，安装器异常退出时保留主程序，更新说明与通道更稳健。
- **AirPlay**：修复 401 认证递归导致的栈溢出；PTP 不可用时回退 NTP 并继续 SETUP；重传校验缓存包序号；重采样长音频索引溢出；取消配对/连接不再冻结或泄漏；seek 时刷新音频；采集启停竞态不再永久静音。

## 已知限制

- AirPlay 的加密兼容、真机配对、多网卡与 NTP 细节等条目仍需真机验证，详见 `docs/` 下相关说明。
- 桌面歌词锁定后的解锁入口为托盘菜单或设置页（透明窗口不接受跨进程鼠标）。
