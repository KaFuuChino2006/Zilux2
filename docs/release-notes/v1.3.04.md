# Zilux2 v1.3.04

播放条重新排布：播放键固定在正中，鼠标移上去展开时按钮不再让位，收起时轻微收小，悬停回来。

## 改进

- **播放键居中**：播放条改为左右两段等分、播放控制独占中间，播放 / 暂停键常驻条子正中。
- **悬停展开不再位移**：鼠标移到播放条上时，条子从两侧同时展开，播放键停在原位不动，点暂停不会因为按钮让位而落空。
- **收放有轻重**：收起时播放键略微缩小、展开时回到原尺寸，与条子共用同一条缓动曲线，不再只是宽度变化。
- **常驻展开统一**：设置为「播放条常驻展开」时，与悬停展开完全一致——封面、标题、上一首 / 下一首、模式、收藏、评论、下载、人声分离、待播队列、进度与音量全部常显，播放键保持原尺寸。

## 修复

- **常驻展开按钮重叠**：常驻展开下「待播队列」按钮不再压到「上一首」上，标题在空间不足时先让位。

## 说明

- 迷你播放器保持原有排布，不受本次调整影响。
