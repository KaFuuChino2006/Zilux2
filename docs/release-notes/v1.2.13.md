# Zilux2 v1.2.13

这一版只修重合歌词的「旧句退场」：散开重新做成两段动画——下一句进来时旧句开始往外散并停住，下下句进来时才消散；同时修掉散开幅度过小、以及散开过程中先弹一下再冻住的顿挫感。

## 修复

- **旧句退场只散一下就不动了**：散开距离原来跟着淡出进度算，而淡出进度只有到「这一句即将隐藏」的瞬间才到 100%，所以观众看到的只是整个行程的一小段。现在散开单独计时：下一句进来就开始，行程铺满到下一句再往后 25%，收尾由透明度接管，中间不再出现静止段。
- **散开范围太小**：单字位移从 `0.5–1.5 × 旧句漂移` 提到 `1.05–1.8 × 旧句漂移`，960 高的画面里单字实际位移约 180–330 px；幅度仍由「重合设置 → 旧句 → 旧句漂移」控制（默认 0.18，范围 0.02–0.4）。
- **散开不够流畅**：散开进度改为先按唱序让每个字错开 32% 行程出发，再套平滑缓动（两端速度为 0），整行像笔尖依次离开纸面，而不是一块板子被匀速推开；同时把每个字的距离差从 0.9–2.4 倍收到 1.05–1.8 倍，避免几个字各飞各的。
- **退场分两段**：下一句进来 → 散开（保持可见）；下下句进来 → 消散（淡出）。拆句开启时，同一句拆出来的每一块各自按这个节奏走。

## 说明

- 其它退场手势（雨、内爆、闪烁、CRT 压扁、涡旋）沿用同一套两段式节奏，只是各自的位移方向与附加效果不同。
- 在重合设置面板里拖动「旧句漂移」可以实时看到幅度变化；「退场」滑块控制的是消散那一段的时长与闪烁次数。
