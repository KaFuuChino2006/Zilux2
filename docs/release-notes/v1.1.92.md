# Zilux2 v1.1.92 — 更新内容

本版本为 v1.1.91 之后「唱片」播放效果的补全与歌词动画修正。

## 新增功能

- **「唱片」效果补全**：
  - 暂停抬臂重做：配重、臂管、唱头壳作为同一刚体绕转轴整体抬起（0.14 rad 平滑过渡），配合影子偏移与唱针光点变暗，不再出现臂管折弯；恢复播放时缓缓落回继续转。
  - 转速更自由：转速滑杆范围扩到 1–78 RPM（可调到极慢，如 16 转 / 8 转），暂停时唱片按该速度缓慢滑停。
  - 新增「旋转方向」：顺时针（真实黑胶默认）/ 逆时针可切换。
  - 新增「歌词横向位置」（20%–80%）：歌词块可左右移动，配合「歌词纵向位置」自由摆放。
  - 移除画面底部的歌名与进度条，画面更干净（设置面板同步移除该项）。

- **「唱片」歌词动画对齐「关闭」样式**：
  - 「旋入」样式下，当前正在播放的行保持半散状态、唱到的字逐个归位，不再一进入播放就整句齐平；下方未播放行按距离逐行打散，越靠近当前行越整齐。
  - 歌词上下切换时补上位移与缩放过渡（0.55s），旧行平滑上移缩小、新行平滑放大就位，不再瞬移。
  - 统一各行字号，聚焦行通过缩放体现层级，切行时不再发生字号突跳。

## 说明

- 版本号唯一来源：`Directory.Build.props`（`1.1.92`）。
- 唱片相关手感参数可在「唱片设置…」调整；独立预览页 `web/preview-vinyl.html` 支持 `?t=` / `?play=` / `?style=` / `?cover=` / `?lyric=` 调试参数。
