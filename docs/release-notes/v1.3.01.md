# Zilux2 v1.3.01

这一版继续把文闪的镜头、颜色和画面收束补完整：文字可以随机带角度入场，镜头会反向抵消倾斜让文字保持水平；新增整幅背景反色、上下电影黑边和底部翻译开关，并修掉自定义文字颜色被覆盖、黑边幅度不生效等问题。

## 新增

- **入场随机角度**：每个字可在原有入场角上再随机偏转 0–360°；另有一档整句随机角度，同一句共用一个角度。
- **镜头跟随旋转**：镜头跟随当前唱字的入场倾斜，并按比例反向抵消，100% 时文字看着保持水平；倾角落位后镜头回正。
- **背景反色**：歌词颜色新增「背景反色」。亮背景用深色、暗背景用浅色，重点词或每隔随机若干句触发一次整幅画面黑白翻转；翻转后保持，下一次触发再翻回。深/浅两色可选，闪烁次数、时长、暗拍占比独立可调。
- **上下电影黑边**：画面上下加入等边黑边，单边占比可在 0–30% 调整；黑边随镜头推拉做贝塞尔曲线运动，并预判下一句的缩放关键帧，跳句时也能连贯过渡。
- **底部翻译开关**：便捷设置 →「歌词」页新增「底部翻译」，默认开启；关闭后隐藏播放条上方的译文兜底条并清空旧译文，歌词行内译文不受影响，设置本地持久化。
- **文闪画面装饰**：新增纸面墨场、版面印刷标记、句边绘线、动态装饰与 PV 图形组，统一跟随「画面装饰强度」。

## 改进

- **黑边运动**：从单句缩放改为跨句关键帧 + Catmull-Rom 插值，提前读取下一句的镜头覆盖目标；相邻句缩放变化过小时跳过关键帧，避免黑边被无意义的句子拖住。
- **反色节奏**：反色闪烁从文字入退场闪烁中拆出，独立控制次数、时长和暗拍占比；整幅画面（背景、文字、装饰、图片、新旧歌词）一起翻转。
- **镜头旋转**：镜头旋转改为反向抵消文字实际倾斜，并把动画缩放一并计入，避免文字倾角与镜头滚转叠加后越转越歪。

## 修复

- **自定义文字颜色被覆盖**：自定义颜色且异色概率为 0 时，重点词不再保留强调色，文字层滤镜也不再把它重写成墨色/纸色。
- **重影不跟随文字颜色**：层叠重影与运动残影改为跟随当前字的填充色/自定义色，不再固定用强调色。
- **反色白底看不见**：反色改为整幅画面翻转，白底黑字会连同背景一起翻成黑底白字。
- **黑边幅度不生效**：黑边基准从 `zoomRest` 改为实际覆盖缩放范围 0.55–1.25，并降低额外平滑，推拉幅度不再被压扁。
- **黑边卡顿**：去掉过长平滑，关键帧只保留有效缩放变化，跨句移动更连续。

## 说明

- 反色的深/浅色与闪烁参数在「歌词颜色 → 背景反色」中调整；黑边占比在「镜头移动」中调整。
- 入场随机角度、整句随机角度与镜头跟随旋转都在文闪设置里；镜头跟随旋转 0% 时保持水平，100% 完全抵消当前唱字倾斜。
- 底部翻译只控制播放条上方的兜底条，不影响逐行歌词里的译文。
