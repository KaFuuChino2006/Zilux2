# Zilux2 v1.1.95

本次更新把「听歌的地基」补了一遍：节拍分析升级到 p0-13，无缝衔接可以按拍点和小节对齐、记住每首歌的过渡，设置页、本地曲库和系统集成也一起补齐。

## 新功能

- **节拍分析 p0-13**：SuperFlux + 分频段通量、滑窗 ACF/tempogram 投票、DP 拍点网格、倍速自动消歧、速度曲线与置信度；过渡和小节长按局部速度换算，变速歌不再跑偏。
- **过渡试放台**：设置 → 过渡 → 打开试放台，A/B 双增益曲线、低频交接点、变速比、响度补偿与实际淡化起点一目了然，可按真实时长模拟播放头。
- **每首歌 / 每个歌单的过渡记忆**：曲目右键「记住这首歌的过渡」，歌单页「记住过渡」；优先级单曲 > 歌单 > 全局。
- **拍点级过渡与长度单位**：过渡起点/B 入场/低频交接吸附真实拍点或强拍；长度可选秒、拍、小节、乐句，并新增「拍点对齐精度」。
- **过渡预告并入「下一首」小卡**：右下角小卡多一行过渡说明，准备后显示实际淡化秒数与起点；可在过渡设置关闭。
- **桌面歌词窗口**：独立置顶歌词条，可拖动、调字号、锁定鼠标穿透、右键关闭；设置 → 通用 里开关。
- **全局快捷键底层钩子兜底**：系统热键被占用（如 1409）时仍能用，WM_HOTKEY 与钩子双通路去重；页面里的空格/方向键不再被音量滑条吞掉。
- **系统媒体控制开关**：可关闭任务栏/音量弹窗的 SMTC 会话，应用内播放不受影响。
- **本地曲库增强**：支持多个音乐文件夹（本地页「文件夹」管理）、缺内嵌封面时自动用目录 `cover.jpg`、本地曲目右键「编辑标签…」直接写标题/歌手/专辑/音轨/年份。
- **智能歌单保存**：场景页/任何带曲目的墙可「存为歌单」，保存到「我的歌单 → 智能歌单」。
- **收听统计**：总时长、最近 14 天、播放最多歌曲/歌手与年度小结（快照式，进入页面时计算）。

## 设置与选项

- 「播放」拆成 播放 / 音效 / 试听 / 过渡 / 分析，「数据」与「实验功能」合并为「存储」。
- 新增在线音质偏好、试听音量与最长试听时长、点击接管续播。
- 睡眠定时：到点前渐弱（0/5/10/15/30 秒），到点后可暂停、暂停并最小化或退出应用。
- 更新检查支持「直连 GitHub」，绕开被限流的系统代理出口。
- 下载：并发数 1–4、文件名模板（`{artist}`/`{title}`/`{id}`/`{quality}`）、完成后自动打开文件夹。
- 迷你播放器：尺寸预设（小/标准/宽）、置顶开关，播放条新增「待播队列」按钮。
- 无缝衔接整组设置统一为快捷设置同款分段滑块；`Shift+X` 本次切歌临时禁用过渡。

## 改进与修复

- 修复媒体键在非当前播放器时被放行、全局热键静默换键却不提示的问题。
- 修复场景页渐变铺满整页、场景图标与「推荐」重复、分桶几乎选不出歌的问题。
- 修复过渡时长设为 30 秒时被结构混音覆盖、歌词衔接开关无效的问题。
- 修复热 cue 用 Shift 清除不生效、槽位错开一位的问题。
- 修复统计页订阅泄漏导致渲染线程卡死、切换页面不回到顶部的问题。
- 修复悬停试听接管瞬间的断音/音量跳变，试听音量改为跟随播放音量。
- 修复迷你播放器补间掉帧，窗口动画改为每合成帧驱动；喜欢墙改用宿主缩略图，封面体积下降 20–60 倍。
- 每日推荐改为全量（网易云/QQ 60 首、私人雷达 120 首），发现页支持滚轮横向滚动，歌单/推荐歌单改为整页。
