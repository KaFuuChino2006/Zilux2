# Zilux2 v1.3.03

新增播放效果「话语」：把整首歌词演绎成一段聊天记录，句句成一条消息，左右分侧、逐字跟唱，并配上一套可独立调节的镜头与动效。气泡外观、出入场动作、引用、拆句、头像、待播列表、输入条与背景均可分别设置。

## 新增

- **播放效果「话语」**：歌词按演唱进度逐句「发送」，整首歌构成一段完整的聊天记录。与文闪、重合、房间、唱片并列，切换互不影响。
- **气泡外观**：提供「随曲」「海蓝」「奶霜」「黑莓」四套配色，其中「随曲」按当前歌曲封面主色实时取色，壳、正文、已唱字、已读双勾与输入中三点统一配色。
- **出入场动作**：入场提供跳豆、拉糖、摇铃，出场提供上浮、侧滑、收拢、淡出，均可设为按句随机；同一首歌每次进入表现一致。
- **逐字跟唱**：未唱、在唱、已唱之间为连续过渡，配合单字上浮、轻微放大与辉光衰减。
- **消息细节**：译文以小字置于气泡内下方；右下角显示时间戳与已读双勾，双勾出现时带弹出动画且时间戳平滑让位；句间空档在下一句所在侧显示「正在输入」三点。
- **引用**：按概率把上一条（另一侧）的内容引到气泡顶部，带竖条与浅底。
- **拆句**：按设定字数把长句切成数段，同句切出的段由同一侧连续发送；拆句概率可调，关闭时保持整句。
- **头像**：左右两侧可分别设置文字（默认「话」「语」）、自定义图片与形状（圆形 / 圆角方形）；左侧未设置图片时自动使用当前歌曲封面。
- **待播列表**：左侧以联系人样式列出播放队列，包含当前播放前 5 首与之后全部曲目，显示封面、歌手、歌名、时长与播放中标记；支持点击切换与滚轮滚动。
- **底部输入条**：按当前句逐字打出草稿，可用发送按钮或回车发出自己的一条消息；发送按钮带悬停放大与按下回弹，草稿区支持文本选区。
- **镜头**：自由跟随为平移加极轻手持倾角与缓慢漂移；可推近至正在演唱的这一句，最大约 2.15 倍，中途换句为横摇过渡，并提供「镜头推近」「推近速度」两项独立调节。
- **背景**：可选封面（虚化亮场）或关闭；关闭后为透明底，页面底色或壁纸直接透出。
- **效果设置面板**：布局、界面、外观、头像、动效五个分区，修改即时预览，支持保存、取消与恢复默认。

## 改进

- **待播列表信息密度**：宽度不足时优先省略文字而保留头像与时长，歌手名与歌名不再被挤成一排省略号。
- **滚动与切换更顺**：滚轮与点击切换都带缓动，行位移与高亮滑块同步过渡，队列变化时不会整列跳动。
- **待播列表与输入条可关闭**：两者都能在「效果设置 → 界面」中关掉，画面空间直接还给对话；待播列表还可以点击左上角「待播」标题收起。

## 修复

- **引用连续成片**：引用按概率均匀分布，不再出现一连串消息都是引用的情况。
- **引用内容溢出**：引用块与文字对齐，长引用不会伸出气泡圆角，文字在块内垂直居中。
- **英文歌词词距过大**：英文歌词的词间距恢复正常，不再越长的词后面空隙越大。
- **待播栏封面闪烁**：左侧封面不再轻微抖动闪烁。
- **收起后发送失效**：收起待播列表后，底部输入与发送仍然可用。
- **全选高亮错位**：输入条全选时高亮正确贴在文字上，不再出现色块与文字错位。
- **待播栏文字被压扁**：歌手名与歌名保持字形比例，宽度不足时以省略号收尾。
- **气泡倾角**：倾斜幅度恢复为轻微角度，不再整条歪斜。

## 说明

- 「话语」的全部参数保存在本地设置中，可随时恢复默认。
- 镜头跟随、镜头推近、推近速度与滚动速度分别独立；将跟随与推近都调为 0 可得到固定机位。
- 待播列表与底部输入条均可在「效果设置 → 界面」中关闭。
