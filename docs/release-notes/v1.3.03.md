# Zilux2 v1.3.03

新增播放效果「话语」：把整首歌词演绎成一段聊天记录，句句成一条消息，左右分侧、逐字跟唱，并用一套可独立调节的镜头与动效系统承载它。气泡外观、出入场动作、引用、拆句、头像、待播列表、输入条与背景均可分别设置。

## 新增

- **播放效果「话语」**：歌词按演唱进度逐句「发送」，整首歌构成一段完整的聊天记录。注册于播放效果列表，与文闪、重合、房间、唱片并列为独立舞台，互不影响。
- **气泡外观**：提供「随曲」「海蓝」「奶霜」「黑莓」四套配色，其中「随曲」按当前歌曲封面主色实时推算发信与收信色。壳、正文、已唱字、已读双勾与输入中三点统一取自同一套配色。
- **出入场动作**：入场提供跳豆、拉糖、摇铃，出场提供上浮、侧滑、收拢、淡出，均可设为按句随机。随机按歌曲与行号确定性抽取，同一首歌每次进入表现一致，不随窗口滚动翻面或改动作。
- **逐字跟唱**：以毫秒级插值把「未唱 → 在唱 → 已唱」做成连续过渡，配合单字上浮、轻微放大与辉光衰减，取代逐字硬切。
- **消息细节**：译文以小字置于气泡内下方；右下角时间戳与已读双勾，双勾出现时带弹出动画且时间戳平滑让位；句间空档在下一句所在侧显示「正在输入」三点。
- **引用**：按概率把上一条（另一侧）的内容引到气泡顶部，带左侧竖条与浅底；随机分布均匀，且不会连续两句都引用。
- **拆句**：按设定字数把长句切成数段，同句切出的段由同一侧连续发送；拆句概率可调，关闭时保持整句。
- **头像**：左右两侧可分别设置文字（默认「话」「语」）、自定义图片与形状（圆形 / 圆角方形）；左侧未设置图片时自动使用当前歌曲封面。图片在本地缩放到 192px 后存档。
- **待播列表**：左侧以联系人样式列出播放队列，包含当前播放前 5 首与之后全部曲目，显示封面、歌手、歌名、时长与播放中标记；支持点击切换、滚轮滚动，并可点击标题收起。
- **底部输入条**：按当前句逐字打出草稿，可用发送按钮或回车发出自己的一条消息；发送按钮带悬停放大与按下回弹，草稿区支持文本选区。
- **镜头**：自由跟随采用平移加极轻手持倾角与缓慢漂移；可推近至正在演唱的这一句，最大约 2.15 倍。焦点移动与缩放各用一条软弹簧，支持中途换句时横摇过去，并提供「镜头推近」「推近速度」两项独立调节。
- **背景**：可选封面（虚化亮场）或关闭；关闭后为透明底，页面底色或壁纸直接透出。
- **效果设置面板**：布局、界面、外观、头像、动效五个分区，修改即时预览，支持保存、取消与恢复默认。

## 改进

- **播放效果接线**：新增舞台只需在播放效果注册表与舞台工厂登记，快捷设置按钮、效果设置入口与存档白名单随之生效，无需再改 UI 表。
- **待播列表信息密度**：宽度不足时优先省略文字而保留头像与时长，避免歌手名与歌名被挤压成密集省略号。
- **列表滚动与切换**：滚轮与点击切换均改为指数缓动，行位移与高亮滑块同步过渡；队列基准变化时按行数做短程补偿，不出现整列跳动。

## 修复

- **引用连续成片**：原随机源对行号末位过于敏感，一旦落到概率线以下会连续命中数百行；改为混洗哈希加黄金比例步进后分布均匀，实测命中率与设定值一致。
- **引用文字溢出气泡**：引用块的宽度未参与气泡排版，导致灰底比文字窄、文字伸出圆角；现将引用尺寸计入宽度与高度，文字改为垂直居中。
- **英文歌词词距过大**：正文绘制前未复位字号，继承了上一条消息时间戳的字号，字按 0.66 倍绘制而占位按 1 倍计算，词间出现随词宽变化的空隙；现于正文段前显式设置字号。
- **待播栏封面闪烁**：滚动位置为小数像素导致封面每帧重采样，同时图像缓存按插入顺序淘汰，正在显示的头像被反复移除重建；现按设备像素对齐，并将缓存改为 LRU。
- **收起待播栏后发送失效**：指针命中在待播栏关闭时提前返回，底部的发送与输入一并失效；现将该判断收进待播栏分支。
- **全选高亮错位**：输入条使用透明文字加画布字形，原生选区仍会铺出不透明色块且行盒位置与画布基线不符；现将原生选区透明化，并按实际选区在画布上自绘。
- **待播栏文字被横向压扁**：绘制时传入最大宽度会让字形被压缩；改为测量后以省略号截断，保持字形比例。
- **气泡倾角过度**：倾角参数被直接当作弧度使用，导致气泡明显歪斜；现按角度换算并限制幅度。

## 说明

- 「话语」的所有参数保存在本地设置中，可随时恢复默认。
- 镜头跟随、镜头推近、推近速度与滚动速度分别独立：可将跟随与推近同时归零得到完全固定的机位。
- 待播列表与底部输入条均可在「效果设置 → 界面」中关闭，或直接点击左上角「待播」标题收起列表。
