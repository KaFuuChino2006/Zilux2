# Zilux2 v1.1.102

这次更新主要重做动态壁纸的「多屏」与「画布」：桌面层改为按真实显示器逐块接管，每块屏可以有自己的一张壁纸、自己的帧率与画面参数；歌词页与桌面背景歌词都能把壁纸透出来，并且不再重复解码同一段视频。

## 新功能

- **多屏独立壁纸**：桌面层按 `Screen.AllScreens` 逐块建表面，每屏一张壁纸、各自 30–240fps 的帧率与画面参数；某块屏没单独设过就跟随全局。屏幕增删会自动重挂，日常换片走原地换流不重建。
- **按屏应用**：素材抽屉底部新增「应用到屏幕 N / 应用到所有屏幕」，N 跟着右栏屏幕示意图里选中的那块走；该屏未接管会先自动接管。
- **画布设置**：顶部「软件内 / 桌面层」两张当前卡各自带一个「画布设置」入口，把移动画布（原裁剪）、水平/垂直镜像、旋转、缩放、模糊、帧率收进同一个弹层；素材抽屉只负责挑图。
- **歌词页透出动态壁纸**：纯壁纸、纯字、拼合、房间、唱片五种样式下都能把壁纸铺在歌词后面，压暗层跟着壁纸一起淡入淡出。
- **桌面背景歌词透壁纸**：背景歌词窗口自己画壁纸与压暗，跟随主屏桌面壁纸切换；选「动态壁纸」以外的样式时会释放这份解码。
- **音频可视化四项偏好**：可视化高度、不透明度、与播放条的间距、频谱柱数（32/48/64/96/128），整体上移到播放条上方不再压住。
- **下拉框统一**：所有原生 `<select>` 换成自绘组件，跟随应用主题，键盘与 Esc 可用；快捷设置与设置页的动态壁纸开关双向同步。

## 改进与修复

- **壁纸**：修复播放歌曲时桌面壁纸定住（换层 key 把端口与 token 算进 URL，导致反复重建）、多屏只有一块有画面、切样式时白闪/黑闪、桌面层开关打开后启动不自动接管（现在按设置直接挂）、侧栏「动态壁纸」与「推荐」图标重复。
- **桌面歌词**：修复切回「纯壁纸 / 封面在左」后不生效、换壁纸不跟随、窗口盖住限帧表面导致画面冻结（限帧改自校正定时器，不再依赖 rAF）。
- **性能**：同一段视频不再被多解一路；歌词页样式关掉后不再建媒体。
- **稳定性**：修复双击歌词页卡死（页面位观察 + 强制回流自喂）、主窗口偶发黑屏。
- **其它**：同步入库此前未提交的转场、分轨、系统音频 OSD 等模块与文档；播放器条与歌词页的层级关系修复。

## 已知限制

- 帧率目前只在桌面层按屏生效；软件内画布仍按页面自身刷新率播放。
- 桌面层与桌面背景歌词都插在图标层下方，壁纸重挂后会把歌词窗口重新抬到壁纸之上，但两者不参与窗口 z-order 排序。
- 多屏壁纸按原始分辨率解码，4K 屏壁纸对 GPU 占用仍然明显。
