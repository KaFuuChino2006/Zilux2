# Zilux2 v1.1.102

这次更新主要重做动态壁纸的「多屏」与「画布」：桌面层改为按真实显示器逐块接管，每块屏可以有自己的一张壁纸、自己的帧率与画面参数；歌词页与桌面背景歌词都能把壁纸透出来，并且不再重复解码同一段视频。顺带把这一路上遇到的小问题一起收了。

## 新功能

- **多屏独立壁纸**：桌面层按 `Screen.AllScreens` 逐块建表面，每屏一张壁纸、各自的帧率与画面参数；某块屏没单独设过就跟随全局。屏幕增删自动重挂，日常换片走原地换流不重建。
- **按屏应用**：素材抽屉底部新增「应用到屏幕 N / 应用到所有屏幕」，N 跟着右栏屏幕示意图里选中的那块走；该屏未接管会先自动接管。
- **屏幕示意图**：右栏按 Windows 真实排布画屏幕块（支持负坐标、竖屏与带鱼屏），节点直接铺当前壁纸的封面，带编号、主屏与「跟随」标记。
- **画布设置**：顶部「软件内 / 桌面层」两张当前卡各自带一个「画布设置」入口，把移动画布（原裁剪）、水平/垂直镜像、旋转、缩放、模糊、帧率收进同一个弹层；素材抽屉只负责挑图。
- **每屏帧率**：帧率上限取该屏实际刷新率（本机 180 / 170 / 200），渲染层按目标帧率取帧；后端再夹一次，写 500 也只会落 200。
- **歌词页透出动态壁纸**：纯壁纸、纯字、拼合、房间、唱片五种样式下都能把壁纸铺在歌词后面，压暗层跟着壁纸一起淡入淡出。
- **桌面背景歌词透壁纸**：背景歌词窗口自己画壁纸与压暗，跟随主屏桌面壁纸切换；选「动态壁纸」以外的样式时释放这份解码。
- **音频可视化四项偏好**：可视化高度、不透明度、与播放条的间距、频谱柱数（32/48/64/96/128），整体上移到播放条上方不再压住。
- **下拉框统一**：所有原生 `<select>` 换成自绘组件，跟随应用主题，键盘、Esc、点外部都能关；快捷设置与设置页的动态壁纸开关双向同步。

## 改进与修复

- **壁纸换片**：换层 key 只比路径，不再把端口与 `?token=` 算进素材身份，播放歌曲时桌面壁纸不再定住重拉。
- **多屏只亮一块**：`hiddenState` 与真实 DOM 不同步，`is-hidden` 撤不掉；改为同时比对缓存与实际 class。
- **桌面层不自动接管**：「桌面层」开关打开后启动即接管，不再需要点一次「接管桌面」。
- **切样式白闪 / 黑闪**：壁纸层去掉写死的黑底，露面前等第一帧 `loadeddata`（400ms 兜底）；压暗层搬进壁纸层内部与它共用一次 opacity 过渡，不再两层各自跳变。
- **切回样式不生效**：桌面歌词页改为手动订阅，样式关掉后不再被状态推流重新建出媒体。
- **换壁纸不跟随**：桌面歌词窗口改拿「主屏桌面层」的载荷，之前拿的是软件内那层。
- **画面冻结**：限帧表面从 `requestAnimationFrame` 改自校正定时器，窗口被别的窗口盖住时不再停帧。
- **双击歌词页卡死**：`refreshVisibility()` 改走带缓存的路径，观察器缩到只盯 `.app` 自身 class 并 120ms 去抖，不再每帧强制回流。
- **主窗口黑屏**：根因是页面位轮询改 class 又强制布局、自己喂自己；整条观察链改成页面切换时的事件驱动。
- **播放偶停**：4 秒巡检对 `paused` 且 `readyState>=2` 的视频补一次 `play()`；连续两轮 `currentTime` 不动时轻推 0.05s 重新出帧。
- **设置页分组标题**「开关 / 在哪显示 / 启动与退出」原来贴着下一行，现在有统一的上间距与小字号。
- **设置页壁纸开关**首次打开全部显示「关」：改为按宿主返回值就地回填，不再等重绘。
- **下拉初值**显示「请选择」：值不在选项里时退回第一项，与原生 `<select>` 一致。
- **下拉滚动即关**：网格懒加载自己滚也会关菜单；改为锚点滚出视口才关，否则跟随定位。
- **下拉可多开**：同一时间只允许一个菜单展开。
- **侧栏图标**：「动态壁纸」换成相框图标，不再与「推荐」的星芒重复。
- **说明文案**：去掉「背景歌词样式」下面那行长提示。
- **歌词遮罩层级**：壁纸页不再压在歌词页上；从歌词页点侧栏「动态壁纸」会先正确退出歌词。
- **性能**：同一段视频不再被多解一路；歌词页样式关掉后不再建媒体；限帧画布与屏幕 1:1，不做上采样。
- **其它**：同步入库此前未提交的转场、分轨、系统音频 OSD 等模块与文档。

## 已知限制

- 帧率目前只在桌面层按屏生效；软件内画布仍按页面自身刷新率播放。
- 桌面层与桌面背景歌词都插在图标层下方，壁纸重挂后会把歌词窗口重新抬到壁纸之上，但两者不参与窗口 z-order 排序。
- 多屏壁纸按原始分辨率解码，4K 屏壁纸对 GPU 占用仍然明显。
