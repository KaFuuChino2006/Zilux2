# Zilux2 v1.1.91 — 更新内容

本版本为 v1.1.9 之后全部改动的累积更新。

## 新增功能

- **歌词页「唱片」播放效果**：新增第四档播放效果「唱片」——整页黑胶唱片场景（黑胶盘体 + 不规则环纹 + 中心专辑封面贴纸 + 整盘旋转 + 唱臂 + 进度弧 + 尘埃 + 逐词歌词 + 底部信息条）。播放时整盘按 33⅓ RPM 转动、暂停惯性减速并抬起唱臂；配套「唱片设置…」面板 7 组 43 行（预设：黑胶 / 午夜 / 酒红 / 奶油，设置存本机 `zilux2.vinylStyle`），并提供独立预览页 `preview-vinyl.html`。
- **「唱片」效果优化**：唱臂重做为俯视真实唱机结构（深色底座圆盘 + 黄铜细圈 + 轴承盖 + 配重圆柱 + 细臂管渐变高光 + 梯形唱头壳 + 黄铜唱针）；唱片大小可调 12%–180%（1600×960 约 97% 即可铺满整窗）；场景歌词逐字动画沿用「关闭」效果的上浮 / 波浪 / 摇曳 / 打字机 / 旋入等样式。
- **「关闭」效果下未播放歌词颜色可自定义**：快捷设置「歌词」页新增「未播放颜色」一行，5 个预设色（墨黑 / 暖沙 / 雾蓝 / 青瓷 / 绛紫）+ 任意取色器，选完立即生效并存本机 `zilux2.lyricUnsung`。
- **键盘驱动媒体键接管**：宿主新增 `WM_APPCOMMAND` 处理——笔记本 / 键盘驱动直接发出的系统「切换音乐」键，在 Zilux2 是当前系统媒体会话时由 Zilux2 响应下一首 / 上一首 / 播放暂停；其它播放器在播时不抢。

## 修复

- **「上一首」改为直接切上一曲**：删掉历史「播放超过 3 秒先回本曲开头、再点才切上一首」的分支，一次点击即切队列上一首；单曲循环仍正常回绕，想重听本曲拖进度条。
- 已唱字颜色与译文颜色保持原主题语义色，不受「未播放颜色」影响；「纯字 / 房间 / 唱片」效果不受该设置影响。

## 说明

- 版本号唯一来源：`Directory.Build.props`（`1.1.91`）。
- 唱片相关手感参数可在「唱片设置…」调整；独立预览页 `web/preview-vinyl.html` 支持 `?t=` / `?play=` / `?style=` / `?cover=` / `?lyric=` 调试参数。
