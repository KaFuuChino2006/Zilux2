# Zilux2 v1.1.94 — 更新内容

本版本为 v1.1.93 之后的一次大更新：DJ 式结构过渡、悬停试听与迷你播放器优化，以及一批播放、浏览与加载体验的改进。

## 新增功能

- **DJ 风格自动过渡（结构混音）**：按歌曲结构（intro / build / verse / chorus / drop / breakdown / outro）挑选入场与让位点；B 从曲首进入，A 在尾奏让位，过渡结束对齐 A 尾奏或 B 的首句唱词；低频交接落在小节线上；两首歌先做响度对齐再淡化；BPM 对齐可在过渡后段平滑回正原速。设置 → 播放 → 自动衔接。
- **「使用场景」预设**：两者兼顾 / 完整播放 / 频繁切歌三档；B 入场时机、过渡长度、低频交接、BPM 对齐范围、响度对齐也都可单独调整。
- **智能接歌（AutoMix）**：待播队列里的「智能接歌」按调性（Camelot）与 BPM 重排后续歌曲。
- **场景歌单**：左侧栏「场景」，按节拍、能量与调性自动分桶（深夜慢歌 / 通勤动感 / 专注轻听 / 高能爆发）。
- **响度均衡与夜间模式**：按每首歌的响度目标做增益补偿；夜间模式压缩峰值、抬高低处。
- **结构驱动舞台**：播放时舞台光效跟随段落与强拍律动。
- **悬停试听**：列表与海报悬停即试听；延迟（0 / 0.6 / 1 / 1.5 / 2 秒）与起点（曲首 / 高潮）可设置；试听中点击该曲，由同一条音轨无缝接续播放，先压低主歌、再平滑淡入。
- **歌曲右键菜单**：立即播放、下一首播放、加入播放队列、收藏、复制歌曲信息。
- **热 cue 与小节循环**：数字键 1–4 记录 / 跳转热 cue（Shift + 数字清除），L 键循环当前 4 小节，播放条显示对应刻度。
- **每日推荐歌单**：首页新增一排「每日推荐歌单」，合并网易云与 QQ 音乐的推荐歌单。
- **播放条标记**：显示高潮段、过渡（交叉淡化）区段，以及热 cue / 循环刻度；高潮段改用重复副歌检测（chroma 相似度）选取首次副歌位置。
- **发现页横向滚动**：排行榜、分类、歌单广场、播客、收藏均支持鼠标滚轮横向滚动。

## 改进

- **迷你播放器**：缩小 / 放大改为跟随屏幕刷新率补间，补间期间只绘制播放卡片、不再整页重排重绘，掉帧明显改善；界面新增播放进度时间、下一首歌名、播放模式与收藏按钮；点击封面 / 标题可直接退出迷你；退出时整页淡入。
- **媒体键**：新增「媒体键始终控制 Zilux2」开关（默认开启）。关闭后恢复系统原生「媒体键跟着当前播放器走」的行为。
- **设置页**：新增「自启动时不显示窗口」；快捷键说明补充窗口内快捷操作；悬停试听新增延迟与起点设置。
- **全局悬停提示**：原生系统提示框换成与应用统一样式的浮层。
- **封面加载**：封面接口支持按显示尺寸生成缩略图，喜欢墙等大量封面的场景加载与滚动明显更轻；无封面曲目改用内联占位图。
- **我的歌单 / 推荐歌单**：从右侧弹层改为整页展示，在线歌单改为卡片排列。
- **私人漫游**：播完当前一批后自动续拉下一批接着播，不再循环重复同几首。

## 修复

- 修复键盘驱动映射的媒体键在 Zilux2 不是「当前播放器」时不生效的问题。
- 修复首页每日推荐 / 私人雷达只展示预览数量（12 / 24 首）、「播放全部」也只排入预览的问题。
- 修复自动过渡时新曲从曲中段（40 秒以后）进入、听感突兀的问题。
- 修复开启响度对齐后过渡瞬间音量突跳、交接缺少双轨分层感的问题。
- 修复悬停试听中点击后音量先变小再恢复、以及点击瞬间停顿的问题。
- 修复喜欢墙向下加载越多、滚动越卡的问题（超大封面与整批挂载）。
- 修复场景页封面渐变铺满整页、场景图标与「推荐」重复，以及场景分桶因 BPM 半 / 双拍误判几乎选不出歌的问题。
