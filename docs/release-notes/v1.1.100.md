# Zilux2 v1.1.100

## 更新日志

### 账号与登录

- 网易云、QQ 音乐的二维码旁新增本机 QQ 头像和昵称，点击即可直接登录。
- 支持展示多个本机 QQ，选择哪个就使用哪个账号。
- 新增「重新检测」，用于刷新本机 QQ 登录状态。
- 网易云新增「QQ 扫码／网易云 App 扫码」切换，默认使用 QQ 扫码。
- 补齐等待扫码、已扫码、手机确认后授权、登录成功、拒绝及过期提示。
- 登录完成后校验平台账号资料，并加密保存登录凭证。

### 在线音乐

- 新增原生接口优先策略：搜索、歌单、榜单、歌词与取流优先走 QQ 音乐 / 网易云原生接口，失败自动回退 web。
- 新增 QQ 请求签名、QMC 加密音频解码与 QQ 原生客户端，补齐原生取流与榜单详情。
- 新增网易云 EAPI 加密客户端，登录态歌单、每日推荐、最近播放与喜欢列表改走原生接口。
- QQ 榜单详情改走原生接口，支持分页；匿名与登录态按权限回退。
- 单次请求 5 秒超时、同源连续失败熔断 60 秒，日志统一 `qq.native` / `netease.native`。

### 人声分离与过渡

- 新增真·人声分离（HTDemucs v4 / ONNX Runtime），播放条支持「原声 / 伴奏 / 人声」三态切换并记忆选择。
- 自动过渡使用分离轨分层混音：B 入场先叠伴奏，再把人声交叉进来。
- 新增「尾小节循环」开关（快捷设置 → 过渡，默认关闭），按缓存就绪情况延长一个小节。
- 过渡时长量化为整小节，A→B 对速，界面与歌词切歌延迟到 B 真正开口。

### 音频与播放

- 新增系统音频输出服务与播放设备选择（跟随系统 / 指定设备）。
- 新增响度测量与预处理音频，供过渡与响度对齐使用。
- 修复短尾窗（3 s / 17 s / 22 s）分离越界报错，改为补静音到模型段长再推理。
- 分离缓存上限 512 MB、最旧淘汰；缓存命中 <100 ms。

### 界面与交互

- 鼠标侧键前进 / 后退接入所有页面级界面，与设置、歌词页一起进历史。
- 设置重构为主 / 子两级，新增缓存三项（占用 / 上限 / 位置）与开发者页（DevTools、日志目录、缓存目录、FPS、布局描边）。
- 快捷设置顶部常驻「封面 + 歌名 + 收藏」，切页缩成一行小卡；修复切 tab 弹高与封面瞬跳。
- 窗口改用无边框 + Win11 DWM 圆角（Win10 `SetWindowRgn` 回退），启动首帧淡入，修复任务栏恢复白框与多屏 DPI 拖动。
- 首页响应式宽度放宽到 78vw / 2560 px，修复 2040 宽收藏卡重叠。
- 「纯字」播放效果修复浅色主题灰雾；歌词长句按剩余宽度自动收窄。
- 新增更新说明、更新提醒与快捷键行组件；移除旧的 PV / 几何场景与设置模块。

### 歌词

- 修复逐字歌词（QRC / YRC）丢失同平台译文轨的问题（±1 s 一对一配对，过滤占位与重复）。
- 歌词选择页不再截断 14 行。
- 「关闭模式」歌词统一半透明白与当前行辉光白，歌曲信息按封面明暗自动反差色。

### 构建与发布

- 人声分离模型随安装包一起发布，首次使用不再下载；优先读取 exe 同级 `models/`，用户目录模型作为回退。
- 修复发布构建遗漏前端源文件导致 CI 失败的问题。
- README 精简：移除版本号与问题反馈入口。
