# Zilux2 v1.1.100

## 更新日志

- 网易云、QQ 音乐的二维码旁新增本机 QQ 头像和昵称，点击即可直接登录。
- 支持展示多个本机 QQ，选择哪个就使用哪个账号。
- 新增「重新检测」，用于刷新本机 QQ 登录状态。
- 网易云新增「QQ 扫码／网易云 App 扫码」切换，默认使用 QQ 扫码。
- 补齐等待扫码、已扫码、手机确认后授权、登录成功、拒绝及过期提示。
- 登录完成后校验平台账号资料，并加密保存登录凭证。
- 人声分离模型随安装包一起发布，首次使用不再下载。

## 修复日志

- 修复网易云本机 QQ 快捷登录分支不可用的问题。
- 移除快捷登录时激活隐藏窗口、移动系统鼠标的操作。
- 修复快捷登录失败后自动弹出登录窗口的问题，改为原页面提示。
- 隔离不同登录流程的浏览器数据，避免账号和凭证混用。
- 防止重复点击触发多次登录，账号失效时不会自动换用其他 QQ。
- 修复扫码方式切换后，旧请求覆盖新二维码或提示的问题。
- 防止同一个二维码重复并发轮询，以及关闭面板后重新启动轮询。
- 刷新网易云 QQ 二维码时销毁旧会话，并自动清理过期后台页面。
