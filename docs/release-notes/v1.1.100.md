# Zilux2 v1.1.100

这次更新把两个平台的登录重新做了一遍：QQ 音乐一个二维码同时支持手机 QQ、微信与 QQ 音乐 App 扫码，网易云补上了 QQ 登录，登录面板改成左侧选平台、右侧扫码的布局；同时把人声分离模型直接打进安装包，首次使用不再下载。

## 新功能

- **QQ 音乐一码通扫**：登录面板只保留一个二维码，手机 QQ、微信、QQ 音乐 App 都能扫；主通道失败会自动回退到手机 QQ 扫码。
- **网易云 QQ 登录**：新增内嵌官方授权页的 QQ 登录（`snsType=5`），授权完成后自动写入账号；与网易云 App 扫码并存。
- **本机 QQ 快捷登录**：登录面板会在二维码旁显示本机 QQ 头像和昵称，点一下就能尝试登录，失败再打开登录窗口。
- **登录面板重做**：左侧竖排选择平台，右侧显示二维码与支持的扫码方式；登录成功不再自动退出，可以接着登录另一个平台，底部提供「进入 Zilux2」。
- **登录后自动刷新**：登录成功或退出账号后，账号按钮、账号面板、我喜欢的音乐、最近播放、我的歌单与首页都会自动刷新。
- **人声分离模型随包发布**：模型直接打进安装包，首次使用不再下载；优先读取 exe 同级 `models/`，老版本用户目录模型作为回退。

## 改进与修复

- **二维码体验**：打开登录面板即自动生成二维码，新码带扫光动画，过期可一键刷新；扫码方式文案改为明确写出平台和动作（手机 QQ 扫码 / 微信扫一扫 / QQ 音乐 App 扫码 / 网易云音乐 App 扫一扫）。
- **构建与发布**：修复发布构建遗漏前端源文件导致 CI 失败的问题；README 精简，移除版本号与问题反馈入口。
- **1.1.99 同步**：v1.1.99 的全部更新内容已并入本版本。

## 已知限制

- 网易云的 QQ 登录需要在宿主内嵌的授权页完成；手机 QQ 单独扫授权二维码只会登录手机端，桌面端请使用「用 QQ 快捷登录」。
