# Zilux2 v1.1.96

这次更新把歌词从软件窗口搬到了桌面上：新增「桌面背景歌词」，歌词页的播放效果可以直接铺在你的壁纸层，听歌时不用打开歌词页也能看到。同时补上了封面在左样式、封面模糊、纯色歌词自定义和快捷设置的整理。

## 新功能

- **桌面背景歌词**：快捷设置 →「背景」页打开后，把歌词页的播放效果镜像到桌面壁纸层（位于桌面图标之下、真实壁纸之上），桌面本身就像播放器。开启期间软件内歌词页暂时不显示歌词，关闭开关后恢复。
- **背景歌词样式**：可在「纯壁纸」和「封面在左」之间切换。封面在左时封面铺满整屏，向右侧渐隐进壁纸，右上角显示歌曲信息与歌词来源；软件内歌词页共用同一套样式。
- **封面模糊**：可调「不模糊 / 轻 / 中 / 重」，「封面之后」可选渐隐到壁纸或模糊铺满整屏。
- **纯色歌词自定义**：歌词颜色选「纯色」时，可在新增的「纯色颜色」里选预设或取色器自定义，唱到的字与光效都会用这个颜色。
- **快捷设置新增「背景」页签**：桌面背景歌词的开关、样式、模糊、铺满集中在这里；原「歌词」页按「歌词内容 / 歌词外观」整理。

## 改进与修复

- **封面清晰度**：歌词页与背景层按显示尺寸请求大图（宿主按宽度向上游要原图/大尺寸，最高 2048），放大封面不再糊。
- **换歌过渡**：桌面背景层与软件内歌词页的封面都改为两层交叉淡入淡出；切歌时歌词先淡出再淡入；冷启动进入软件时会直接补发当前歌词，不需要先切一首歌。
- **软件内「封面在左」**：加宽模糊区，修复模糊层没有封面图、右半区透出桌面的问题。
- **快捷设置面板**：限高并让内容区滚动，小窗口下底部页签不再被裁；滚动条不再闪烁、切页签时开关位置不再挪动，高度动画也恢复平滑。
- **桌面背景歌词细节**：关闭播放效果时字号放大；修复歌词列表反复重绘导致的上下跳；唱片场景在壁纸层按比例缩放画布，改善帧率。
- **本地曲库**：附加曲库根目录接入目录监控，新增/删除/改名文件会自动刷新，标签写入与删除也会同步。
- **窗口与统计**：修复最大化窗口在单实例激活时被还原、隐藏启动唤醒后窗口不置前；修复统计清空后排队写入把空数据又写回的问题；快捷键回落成功时补充悬浮提示。
