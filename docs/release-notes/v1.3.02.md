# Zilux2 v1.3.02

这一版把文闪的运镜、旧句退场和句边图形补成可独立调节的完整一套：镜头移动与缩放各有一条贝塞尔速度曲线，重合也有自己的错帧与曲线；文闪退场时长可调到 0 秒；镜头撞击会按运镜速度自动削弱；句边动态图示改成贴字的几何边轨、进度格与刻度。

## 新增

- **文闪句边几何图示**：按句独立概率出现，边轨、进度格、四角括号、逐字刻度和扫描游标都贴着文字最终包围盒走，颜色跟随每个字自己的颜色；出现与消失复用文闪的闪烁节奏，可单独调节出现概率、密度和流速。
- **文闪独立退场时长**：新增「上一句退场 → 退场时长」，范围 0–5 秒，默认 2.6 秒；0 秒表示停留结束后直接切走，不再被最小退场时长兜底。
- **镜头移动 / 缩放双曲线**：文闪的平移与缩放拆成两条四点贝塞尔速度曲线，可分别拖动；缩放使用更宽的响应范围。
- **重合镜头曲线与独立错帧**：重合的镜头移动、缩放也有自己的速度曲线，并新增「镜头错帧」参数，不再共用文闪的设置。
- **撞击高速弹性削弱**：镜头目标速度越快，撞击的位移、回摆和拖尾越弱；慢速运镜保持原弹性，可调削弱比例与起始速度。

## 改进

- **撞击位移改用像素**：文闪与重合的横向/纵向撞击改为直接填写像素距离，去掉容易和总位移重复的倍率；撞击曲线预览同步按像素重画。
- **镜头错帧可合并/分开**：位置与缩放的错帧时长可以共用一个值，也可以拆开分别调节。
- **动态图示不跟文字闪烁**：句边图形使用自己的出生与句子进出场透明度，不会跟着单字闪烁忽明忽暗；尺寸固定为整句落定后的最终包围盒，不会随文字放大缩小。
- **文闪默认值更新**：把当前调好的文闪参数固化为软件默认值，新安装或恢复默认时直接得到这套观感。

## 修复

- **高速运镜撞击过弹**：撞击原先读取弹簧实际速度，换句第一帧弹簧尚未起步，导致削弱不生效；改为跟踪镜头目标速度后，快速运镜的弹性被正确压住。
- **退场时长无法归零**：文闪退场路径不再强制取「散开时长 × 1.2」的下限，0 秒可以真正立即消失。
- **句边图形随字闪烁**：逐字刻度与字角标记不再乘单字透明度，只按自己的出生进度淡入。

## 说明

- 文闪句边图示在「动态图示」中开关；出现概率按句独立抽取，0% 等于关闭。
- 文闪退场时长只影响文闪，重合仍在「旧句 → 退场时长」里调节。
- 撞击的「横向位移 / 纵向位移」单位是像素；「高速弹性削弱」为 0 时恢复旧版全弹性。
