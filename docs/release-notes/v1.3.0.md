# Zilux2 v1.3.0

这一版把「文闪」做成完整的歌词播放效果：整句链式排版、镜头跟随、入场/退场闪烁、逐字色块与镂空、全词辉光与重点词流动渐变，并把原本写死的一套参数全部搬进设置面板。歌词页的底部控件与右上角关闭按钮也会在非默认效果下自动收起；背景/壁纸切换和重合镜头曲线一并修顺。

## 新增

- **文闪播放效果**：新增独立播放效果。复用重合的逐字入场与旧句停留，但退场不再散开、淡出或整幕缩放——旧句保持原样，到最后一次亮拍后原地消散；逐字闪烁、纯色块、镂空和辉光都同时作用于退场。
- **整句链式排版**：横排按整行、竖排按整列下落，下一句首字接在上一句最后一个字的下方，左边缘对齐；文字允许出画面，不为了适配屏幕而缩小或换行。新增 8 方向链（↓↘→↗↑↖←↙），支持固定方向、每句轮转和每句随机；十字/斜向都用整行包围盒计算落点，避免压住上一句。
- **文闪设置面板**：入场倍率上下限、贝塞尔曲线、整句/拆分短句/混合、拆分粒度（1–8 字/词，中日泰等按字、英文韩文阿拉伯文等按词）、出现顺序（按歌词时间/短句随机/整句随机）、入场动作（只用缩放/重合逐字/叠加两者）、入场延后、收束时长、入场拉伸与抽帧级数、入场模糊、闪烁次数/窗口/暗拍占比/暗拍亮度、纯色块概率/颜色/外扩/不透明度、镂空概率/描边、整句色块概率、入场后抽帧放大与波浪、辉光强度/半径/普通字比例/渐变颜色与流动速度/色带密度、镜头抽帧、画面帧率、撞击曲线。
- **全词辉光**：所有文字都有辉光，普通字用自身字色，重点词再叠三段流动渐变；渐变颜色可跟随重点词或自定义 A/B/C，速度、密度、强度、半径和普通字比例都可调。
- **歌词页底部自动收起**：使用非默认歌词效果且正在播放时，播放条、下一首卡、队列按钮和右上角「收起歌词」会一起收起；鼠标移动立即恢复，指针悬停或键盘焦点还在控件内时不收起。默认效果与未播放时保持常显。
- **重合镜头曲线**：重合设置新增镜头错帧、平移速度曲线和缩放速度曲线；镜头可以在下一句出现前提前叠加，平移与缩放各自按贝塞尔曲线推进。

## 改进

- **文闪镜头跟随**：横排/竖排都会跟随当前唱字平移，链式文字不会只靠自身布局跑出画面；镜头不做滚转、手持抖动和落定回弹，避免和文字闪烁抢注意力。
- **拆分与排序**：拆分句现在可以按语言分别按字/按词切分，随机出现只打乱入场时间窗，不移动文字位置；混合档相邻行交替使用整句与拆分短句。
- **壁纸/背景切换**：修正应用到软件内后主界面仍停在封面背景、切回封面/自定义背景时壁纸层仍盖在上面、关闭背景时先闪一下再淡出的问题；启动早期读不到页面壁纸开关时会自动补读，进入歌词页不再需要手动再切一次。
- **重合镜头过渡**：镜头错帧和速度曲线读写分离，平移与缩放可以各自设置推进节奏。

## 修复

- **文闪退场后原文字回闪**：退场闪烁窗口结束后透明度不再回落到 1，播完保持透明，不会在原位重新出现再消失。
- **拆分短句退场等整行**：每个短句按自己的 lyricEndTime 加退场窗口收场，不再等后面两句；当前句唱完后会等下一句出现 0.5 秒再进入退场。
- **七种入场样式看起来没加载**：入场位移不再被大倍率收束盖住，入场延后/收束时长会同时拉长逐字位移与旋转；链式样式分配不再让整行反复落在同一种样式上。
- **重点词异色只生效在辉光**：文字层滤镜在保留逐字填充色时不再把字色统一重写成墨色/纸色，异色概率会同时作用于文字与辉光。
- **流动渐变硬切**：三段渐变改为环形平滑过渡，A→B→C→A 不再出现明显接缝。
- **文闪边缘印痕**：画面边缘的裁切印版已移除；乐谱线标记保留，并补上与文闪一致的闪烁入场/退场。
- **歌词页控件残留**：自动收起时不再只藏播放条，下一首卡、队列按钮和右上角关闭按钮会一起进退。

## 说明

- 文闪的闪烁参数由「闪烁节奏（入场/退场）」统一控制，入场触发概率按镜头种子决定，0% 关闭。
- 拆分粒度只作用于「拆分短句/混合」档；「整句」档下滑杆置灰，竖排不会自动把整句改成拆分句。
- 只有公开仓库的 Release 才能被应用内更新检查到；本版发版后可在「设置 → 更新」看到更新日志并自动下载安装包。
