# Zilux2 里程碑 6：全屏 3D 登录空间

日期：2026-10-18
状态：已发布便携版，等待用户实测扫码

## 目标（用户原话要点）

- 「整个播放器都在一个 3D 空间里面的样子」
- 「先把其他页面全部删除，左侧导航栏也删除，底部播放条也删除，歌词也删除，先做好网易云登录和 QQ 音乐登录，参考那三个开源项目」

因此本里程碑做减法：App 启动后不再有首页 / 搜索 / 设置 / 库 / 歌单页 / 播放条 / 歌词面板，只有一块全屏 3D 空间和两块平台登录卡片。

## 形态

- 启动动画（粒子星云 + ZILUX 字标）结束后进入 3D 空间。
- 空间里只有两块悬浮玻璃卡片：**网易云音乐**、**QQ 音乐**。
- 点击卡片 → 卡片内直接出现二维码（不弹窗、不跳页）→ 手机扫码 → 卡片就地变成账号卡（头像 / 昵称 / 会员徽标）。
- 底部一条极简状态提示；无其它 UI。
- 登录态由宿主持久化（`%LOCALAPPDATA%\Zilux2\account.json`，DPAPI 加密 Cookie），下次启动直接显示已登录卡片。

### 3D 表现

- 全屏 WebGL2 场景：浅色空间星尘（自定义 shader 点精灵，缓慢漂浮/闪烁）+ 地面柔光。
- 两块卡片是 web 端 Canvas2D 绘制的纹理（白磨砂玻璃、平台徽标、二维码、状态文案），贴到 three 平面上；悬停时抬起/放大/回正，镜头随鼠标轻微视差。
- 单 canvas、单 rAF，纹理只在登录状态变化时重绘；窗口隐藏时跳过渲染；像素预算 4.2MP、DPR 上限 2。

## v1.4 修订（2026-10-18 晚）

针对真机反馈「进入空间按钮点不了」「两个平台卡片鼠标移上去的动画有点问题」：

1. **按钮点不动**：v1.3 给 `.space-canvas` 加了 `z-index:1`（为了压在进入后的背景层之上），但品牌、标题、按钮、返回、状态条等浮层没有显式 `z-index`（默认 auto），结果 3D 画布盖在按钮上面，点击被 canvas 吃掉。修复：浮层显式设置 `z-index: 3`（品牌/标题/状态）与 `z-index: 4`（主按钮区/返回按钮），canvas 保持 1。现在鼠标点「进入 Zilux2 空间」可正常进入。
2. **卡片 hover 抖动**：原来的 hover 命中检测直接对"正在做位移动画的卡片"做 raycast——卡片一浮起/放大，指针与卡片的相对位置随之变化，在卡片边缘附近会反复触发 hover 进入/离开，表现为抖动/闪烁。修复：每张卡新增一个**固定在基础位置上的不可见命中平面**（只跟随缓慢的悬浮 bob，不跟随 hover 位移），raycast 只打命中平面；同时 hover 表现统一改由 0→1 的平滑进度插值（上浮 0.10、放大 3.2%、朝向回正 32%、前倾 1.8°），不再出现属性跳变。
3. 验证：`research/shots/space-hover-netease.png` / `space-hover-qq.png`（真实宿主 hover 状态）、`space-click-entered.png`（鼠标点击按钮进入空间）、`pub2-hover.png` / `pub2-entered.png`（发布版同项验证）；`pnpm build` 通过，便携版已重发（web payload 660,166 B）。

## v1.8 修订（2026-10-18 深夜）

**问题**：启动页的粒子星云「消失」了。

**根因**：白色磨砂重构时 `#splash` 变成了全屏不透明的浅色渐变（`z-index:100`），而粒子画布 `#stage` 一直挂在 `body` 上（`z-index:0`），被 splash 的磨砂底完全盖住；另外粒子调色板仍是浅色主题下的近白/低饱和淡彩（`#ffffff/#f4f0ff/#b9a8ff…`），即使能透出来，在浅色磨砂底上也几乎看不清。

**修复**：

## v1.10 修订（2026-10-19 凌晨）：玻璃透明质感 + 自定义外观面板

**需求**：玻璃没有透明感/玻璃质感；转动视角时悬浮玻璃会钻到大玻璃下面看不见；玻璃厚度要可自定义；右侧加一个与「设置」分开的「自定义」面板，自定义背景图也放这里。

**1. 玻璃材质重做（透明覆盖层方案）**
- 放弃 MeshPhysicalMaterial 的 transmission/ior 路线：它在无真实环境贴图时会浑浊发灰，加上 PMREM 环境贴图又会整体偏蓝紫。
- 改为「几乎全透的覆盖层 + 边缘反光」：玻璃顶面是一张 Canvas 纹理（中心近乎全透，四周一圈柔和白色高光 + 大块斜向扫光），玻璃下方单独一层「空间背景」（默认浅色渐变 + 紫/青/粉/黄光斑，可替换为用户图片）；侧壁用竖向渐变纹理（底部冷蓝 → 顶部近白）。
- 修复两个导致「半透明变白板」的隐蔽问题：①ExtrudeGeometry 的前后盖默认复用材质数组第 0 个材质，侧壁渐变纹理把盖面涂成了白渐变 → 给玻璃/小玻璃都加一个 `colorWrite:false` 的隐形盖面材质；②ShapeGeometry 的 UV 是形状坐标（±宽/2），玻璃下方背景纹理必须 `repeat(1/宽,1/高) + offset(0.5,0.5)` 归一化，否则 UV 越界被 clamp 成纯白。
- 结果：玻璃板与小玻璃片都能透出下方背景色，边缘有玻璃反光；厚度由侧壁几何体现（斜视角最明显）。

**2. 小玻璃不再钻到大气下面**
- 小玻璃片改为 `renderOrder 6/7`，玻璃顶面/侧壁 `2/3`，均关 `depthWrite` 由绘制顺序保证永远画在大玻璃之上；同时提高小玻璃悬浮高度（`CHIP_BASE_Y = 1.02`）。

**3. 右侧「自定义外观」面板（与设置分开）**
- 右侧中部新增铅笔按钮（与左侧功能栏同一套玻璃质感），打开独立面板，含：
  - **玻璃厚度**滑块 0.10–1.60（默认 0.62，实时重建侧壁几何，小玻璃一起变厚）；
  - **玻璃通透度**滑块 30%–100%（默认 94%，控制覆盖层浓淡：越低越接近磨砂）；
  - **空间背景图**：选择本地图片（自动压缩到 1600px 内 JPEG），显示在玻璃下方；可一键清除。
- 持久化到 localStorage（`zilux2.space.custom`）；QA 参数 `?panel=custom`（打开面板）、`?thickness=`、`?transmission=`（快速调参）。

**验证**：headless `space-transparent5.png`（透明玻璃+6 片小玻璃）、`space-t1/t2/t3.png`（厚度 0.62 / 1.4 / 0.25+磨砂 45% 三档对比）、`custom-login.png`（自定义面板）；真实宿主 `host-glass.png`（厚度 1.2 斜视角厚侧壁）、`host-custom.png`（面板）。发布版 web payload 816,048 B。

## v2.3 修订（2026-10-19 凌晨）：拖动视角松手惯性

问题（m08640）：「鼠标拖动视角转的时候只要一松手直接就定住了，不丝滑」。

- **根因**：`floatScene.ts` 的 `pointerup` 里有一句 `orbitYaw = orbitYawTarget; orbitPitch = orbitPitchTarget;`，松手瞬间把当前角度直接跳到目标角度；同时拖动过程中松手后没有任何惯性，所以感觉「啪」一下定住。
- **修复**：
  1. 删除松手时的瞬移赋值；
  2. 拖动时改成目标角累加（`orbitYawTarget -= dx * 0.0055`），并记录横向/纵向速度（×0.55）；
  3. 松手后每帧把速度加到目标角上并衰减（`yawVelocity *= 0.9`），当前角以 7.5/s 平滑追随，形成「滑行一段再缓停」的惯性手感；
  4. 惯性滑到边界会被 ±55°/2°~36° 的 clamp 自然截停。

## v2.33 新增（2026-10-20）：3D 设置面板 —— 面板内滚轮 / 任意拖动 / MSDF 矢量文字

### v2.34 补丁（2026-10-20）：设置面板改成真正的空间实体

- 反馈：面板看起来像贴在屏幕上的 HUD，不像在 3D 空间里。
- 改法：`settingsBoard.ts` 用世界坐标 `panelPos` 固定面板位置，打开时放在相机前方 `PANEL_DIST = 4.2` 处并只算一次朝向 `panelYaw`；之后转视角/平移/缩放时面板留在空间原位，产生视差与透视。拖动改为世界坐标平移（`dragDist` 锁定拖拽起始距离，`perPixel = 2*dragDist*tan(fov/2)/canvasH`），`clampPanelInSpace()` 只做粗范围保护（x ±7、y -2.5..4.5、z -0.5..14，距离 1.2..20）。
- 每帧：`group.position.copy(panelPos); group.position.y -= intro*0.12; group.scale = panelScale()*(0.9+0.1*openAmount); group.rotation.set(-0.07, panelYaw, 0)`（轻微后仰）。
- 打开面板时重新 `placePanelInFront()` 回到当前视野正前方；新增 Esc 关闭（`floatScene.ts` 的 window keydown，仅在面板打开时生效）。
- 验证：`research/qa/cdp-board-spatial.mjs`（打开→面板内滚轮→×→重开→中键平移/滚轮缩放看视差→Esc）。
