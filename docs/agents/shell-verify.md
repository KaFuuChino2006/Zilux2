# shell 宿主修复 — 重启验证清单

> 覆盖 5 项：窗口边框移除、启动/任务栏恢复、圆角、多屏 DPI 拖动、网易云喜欢歌单。
> 改动在 `src/Zilux2/**`（未发布、未覆盖安装目录）。验证需用新构建启动；运行中的 v1.1.97 是旧代码。
> 宿主日志：`%LOCALAPPDATA%\Zilux2\logs\host.log`。

## 1. 窗口外观

- [ ] 窗口四周没有任何主题色描边/底框（把页面停在沉浸播放页、照片页再看一遍）。
- [ ] 四角是平滑圆角，不是直角（Win11 由 DWM 画；Win10 走 SetWindowRgn，允许轻微锯齿且无 DWM 阴影）。
- [ ] 最大化 → 还原、进出迷你播放器后圆角仍正确，没有直角色块或旧尺寸残留。
- [ ] 页面本身的圆角卡片不被窗口裁剪切掉（如果切掉，说明 Win10 region 半径过大，记录截图）。

## 2. 启动与恢复

- [ ] 冷启动不先闪一块空白主题色窗壳；内容就绪时淡入（日志出现 `window.fadeIn reason=first-content`）。
- [ ] 页面异常/初始化失败时，窗口 5 秒内仍会出现（日志 `window.reveal fallback: content was not ready in time`），错误面板可见、可点。
- [ ] 任务栏最小化 → 点任务栏恢复：内容直接出来，不只剩底框
      （恢复时日志应有 `webview2.surface nudge ...`）。
- [ ] 托盘隐藏 → 托盘/热键恢复：同样不空壳；连续最小化/恢复 3 次以上仍正常。

## 3. 缩放与页面交互

- [ ] 左/右/上/下四边都能拖动缩放；四角能斜向缩放；拖动跟手、没有跳变。
- [ ] 页面边缘的按钮、链接、输入框可以正常点击（不被缩放热区吞掉）。
- [ ] 页面右侧/底部滚动条可以正常拖动（不被缩放热区抢走）；`overflow:hidden` 的容器边缘仍可缩放。
- [ ] 页面中部鼠标拖动/选中文本正常，不会误触发窗口拖动（标题栏除外）。

## 4. 双显示器 + 不同缩放

- [ ] 从 100% 屏拖到 125%/150% 屏（及反向）：窗口跟手、不卡住、不被弹回原屏。
- [ ] 跨屏后标题栏/边缘仍能拖动和缩放；最大化/还原落点正确。
- [ ] 日志出现 `window.dpiChanged dpi=...`，且没有 `window.clamp failed`。
- [ ] 已知取舍：拖动过程中标题栏可短暂移出屏幕，松手后会被钳制回工作区。

## 5. 网易云在线库

- [ ] 登录后「我喜欢的音乐」是自己账号的喜欢列表（标题、数量、封面正确）。
- [ ] 日志里 `GET netease/library playlists uid=... ok N playlists liked=<id> foreignLiked=N`：
      - `foreignLiked > 0` 说明拦住了别人添加进库的喜欢歌单；
      - `liked` 仍应有值（自己的那个）。
- [ ] 若出现 `liked=none` 且 `foreignLiked>0`：上游没返回自己歌单的 `creator.userId`，
      属于预期外情况，回来找 shell（点赞/取消赞会 404）。
- [ ] 点赞、取消赞、红心状态检查仍正常，没有「没有找到我喜欢的音乐」报错。

## 已知风险（非阻断）

- WPF `Window.Opacity` 对 WebView2 子 HWND 是否生效、以及表面 nudge 是否足以修复任务栏恢复空壳，
  都需要真机确认；最坏情况仍可能出现空白，需要 WebView2 controller 级处理（源码层已到上限）。
- Win10 圆角硬裁剪的锯齿/无阴影是固有取舍；半径 8 DIP 已对齐 Win11 DWM 默认。
- 页面边缘 5px 热区在极端情况下仍可能与紧贴边缘的自定义控件冲突，可用 `data-no-window-resize` 标记退出。
